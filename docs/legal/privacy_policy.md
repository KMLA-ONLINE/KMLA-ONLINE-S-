# KMLA Online 개인정보처리방침

시행일: 2026년 10월 11일

민족사관고등학교 과학기술부(이하 "운영자")는 「개인정보 보호법」에 따라 KMLA Online(이하 "서비스") 이용자의 개인정보를 보호하고, 관련 고충을 원활하게 처리하기 위해 이 처리방침을 둡니다.

## 1. 처리 목적

운영자는 다음 목적으로만 개인정보를 처리합니다.

- 회원 가입과 학교 구성원 확인, 계정 관리, 본인 확인(이메일 인증, 비밀번호 재설정)
- 커뮤니티 서비스 제공: 프로필, 그룹, 게시물·댓글·반응, 알림, 급식·시간표·생일·스토리·예약 기능
- 약관 위반 대응, 신고 처리, 분쟁 해결과 문의 응대

## 2. 처리 항목

**가입할 때 (필수)**

| 구분   | 항목                                                                 |
| ------ | -------------------------------------------------------------------- |
| 공통   | 이메일, 비밀번호(암호화 저장), 이름, 사용자 유형(재학생·졸업생·교사) |
| 재학생 | 성별, 학번, 생년월일, 기수, 계열                                     |
| 졸업생 | 성별, 기수, 계열                                                     |

**가입할 때 (선택, 입력한 경우에만 수집)**: 전화번호, 졸업생의 학번·생년월일

**서비스를 이용하며 회원이 입력하는 정보**: 프로필 사진, 커버 사진, 소개, 생일, 전화번호, 연락용 이메일, 반, 부서, 기숙사 방, 재입학 여부, 프로필 주소(공개 ID), 시간표, 게시물·댓글·반응과 첨부 이미지, 예약 기록, 알림 설정

**자동으로 생성·수집되는 정보**: 로그인 기록과 접속 IP 주소, 알림을 받기 위한 기기의 푸시 구독 정보, 서비스 이용 기록(알림 열람, 피드 노출 등)

## 3. 다른 회원에게 공개되는 정보

서비스는 학교 구성원끼리 서로를 알아보는 커뮤니티이므로, 다음 정보는 승인된 다른 회원에게 표시됩니다.

- 프로필에 입력한 이름, 사진, 기수, 계열, 학번, 반, 부서, 기숙사 방, 성별, 생일, 전화번호, 연락용 이메일, 소개
- 실명으로 작성한 게시물, 댓글과 모든 반응의 작성자

공개하고 싶지 않은 선택 항목은 프로필 편집에서 비워 둘 수 있습니다. 익명 게시물과 익명 댓글의 작성자는 다른 회원에게 표시하지 않습니다.

## 4. 보유 기간과 파기

1. 회원 정보는 탈퇴할 때까지 보유합니다. 졸업해도 계정은 유지됩니다.
2. 탈퇴하면 개인 식별 정보를 지체 없이 파기합니다. 게시물은 이용약관 제13조에 따라 "탈퇴한 사용자" 명의로 남습니다.
3. 삭제한 게시물과 기간이 정해진 기능의 기록(스토리, 알림, 예약 등)은 탈퇴 전이라도 서비스의 삭제 정책에 따라 삭제합니다.
4. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다. 운영자는 개인정보를 종이로 보관하지 않습니다.

## 5. 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 다만 수사기관의 요청 등 법령에 특별한 규정이 있는 경우에는 그에 따릅니다.
