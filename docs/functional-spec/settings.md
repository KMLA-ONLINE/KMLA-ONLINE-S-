# 메뉴 및 개인 설정

## 15. 메뉴 및 개인 설정

메뉴에서 여는 학교 기능(급식, 생일, 스토리, 시간표)의 명세는 §17로 옮겼다. §15.6과 §15.8–15.10은 비워 두며 다시 쓰지 않는다.

### 15.1 메뉴 홈

- 모바일과 데스크톱 모두 기존 `/menu` 경로에서 메뉴 홈을 제공하며, 화면과 내비게이션 이름은 "메뉴", 내비게이션 아이콘은 도형(`Shapes`)으로 표시한다.
- 본문은 "학교 기능"과 "학교 사이트" 두 구역으로 나눈다. 학교 기능에는 급식(§17.4), 학교 공지(§17.10), 시간표(§17.7), 공강 · 노래방(§17.1, §17.2), 생일(§17.5), 기부물품 여섯 타일을, 학교 사이트에는 외부 사이트 세 타일(§15.13)을 직접 배치한다. 기부물품은 선물(`Gift`) 아이콘으로 표시하고 `/menu/donations`로 이동한다. 기부물품의 회차·신청·엑셀 관리 동작은 §17.9를 따른다. 학교 공지는 확성기(`Megaphone`) 아이콘으로 표시하고 `/menu/notices`로 이동한다. 스토리는 홈 레일(§6.6)에서만 다룬다.
- 학교 기능은 모바일에서 2열 × 3행, 데스크톱(`md`, 768px 이상)에서 4열 × 2행으로 배치한다. 학교 사이트는 모바일에서 아이콘과 이름을 가로로 놓은 작은 타일 2열 × 2행, 데스크톱에서 3열 × 1행으로 배치한다. 두 구역은 같은 타일 스타일과 제목으로 정돈한다.
- 데스크톱 본문은 최대 약 768px 폭으로 중앙 정렬한다. 설명이나 오늘의 정보를 추가하지 않으며, 화면 높이를 채우려고 타일을 확대하지 않는다. 하단 여백은 허용한다.
- 모바일 화면 헤더 우측에는 설정(`/settings`) 버튼을, 그 오른쪽에는 내 프로필로 바로 이동하는 아바타를 둔다. 앱 관리자에게만 설정 버튼 왼쪽에 관리자 페이지(`/admin`) 아이콘 버튼을 표시하며, 접근성 이름과 툴팁은 "관리자 페이지"다. 프로필 카드는 본문이나 설정 화면에 두지 않는다.
- 데스크톱 전역 헤더의 아바타는 호버해도 배경색이 바뀌지 않으며 키보드 포커스 표시는 유지한다. 드롭다운은 내 프로필, 설정, 관리자 페이지, 로그아웃 순서이며 관리자 페이지는 앱 관리자에게만 표시한다. 학교 사이트 바로가기 그룹은 두지 않는다. 넓은 홈의 학교 기능 요약과 공강·노래방 바로가기는 유지한다(§6.7). 홈은 필요한 정보 요약, 메뉴 홈은 학교 기능 전체의 진입점 역할을 한다.
- 계정·앱 설정과 서비스 안내는 설정 화면(§15.3)에서 제공한다. 관리자 첫 화면의 뒤로가기는 메뉴(`/menu`)로 이동한다.

### 15.2 알림 설정

- 설정 화면의 알림 설정 항목에서 `/settings/noti`로 이동한다. 모바일과 데스크톱 알림 탭에는 알림 설정 버튼을 두지 않으며, 알림 설정 화면의 뒤로가기는 `/settings`로 이동한다.
- Web Push 전체 설정과 현재 브라우저 권한 상태를 표시한다.
- Web Push를 지원하지 않는 환경에서는 지원하지 않음을 안내하고 켜기 기능을 제공하지 않는다.
- 브라우저 권한이 거절된 상태에서는 권한 요청을 반복하지 않고 브라우저 설정 변경 방법을 안내한다.
- Web Push 전체 설정을 켜면 보통 및 높음 중요도 유형을 기본으로 켠다.
- 전체 설정을 변경하는 동안 진행 상태를 표시하고 중복 조작을 막는다.
- 사용자는 다음 유형별 Web Push를 끌 수 있다.
  - 댓글 · 답글: 내 게시물에 달린 댓글, 내 댓글에 달린 답글
  - 내 타임라인: 다른 사람이 내 타임라인에 남긴 게시물
  - 그룹 운영 소식: 가입 요청과 승인, 역할과 그룹 정책 변경
  - 계정 · 권한: 가입 승인과 관리 권한 변경
  - 학교 기능: 공강 예약 등 학교 부가 기능 소식
- 그룹별로 앱 알림함 수준과 직접 관련 활동 Push를 따로 설정한다. 앱 알림함 수준을 `없음`으로 두면 해당 그룹의 콘텐츠 Push도 함께 끈다.
- 낮음 중요도의 새 그룹 게시물 Push는 앱 알림함 수준이 `전체`인 그룹에서만 켜거나 끌 수 있다.
- 반응은 인앱 전용이므로 Web Push 설정을 제공하지 않는다.
- `알림에 메시지 내용 가리기`를 제공한다. 기본은 꺼짐이며, 켜면 새 메시지 Push에 내용 대신 일반 안내만
  표시한다(§13.17). 잠금 화면에서만 내용을 가리려면 기기의 알림 미리보기 설정을 쓰도록 함께 안내한다.
- 현재 설정이 실제로 무엇을 전달하는지 요약해 보여주고, 설정을 바꾸면 즉시 갱신한다.
- Web Push 전체 설정은 이 기기에만, 유형별과 그룹별 설정은 계정의 모든 기기에 적용된다는 점을 각 설정 옆에 표시한다.
- 유형별 Web Push를 끄면 해당 알림이 앱 알림함에는 계속 쌓인다는 점을 안내한다.
- 운영 조치는 Web Push 전체 설정이 켜져 있는 동안 항상 전달되며 유형별 끄기를 제공하지 않는다.

### 15.3 설정과 실험실 기능

- 설정은 `/settings`에서 제공하며 계정, 앱 설정, 서비스 안내로 분류한다. 첫 화면의 뒤로가기는 메뉴(`/menu`)로 이동한다.
- 계정에는 비밀번호 변경(`/settings/password`)을 둔다.
- 앱 설정에는 알림 설정(§15.2), 데스크톱 홈 우측 사이드바 설정과 실험실을 둔다.
- 홈 우측 사이드바 설정은 1024px 이상에서만 표시한다. 전체 스위치와 생일·급식·시간표 개별 스위치를 제공하며 모두 기본으로 켜져 있다. 전체가 켜져 있을 때만 개별 스위치를 하위 항목으로 표시한다.
- 전체를 끄면 개별 스위치를 숨기되 선택은 보존하며, 다시 켜면 이전 구성을 복원한다. 개별 항목을 모두 꺼도 전체 스위치는 켜진 상태를 유지한다.
- 별도 저장 버튼 없이 변경을 즉시 저장·반영한다. 선택은 브라우저별로 저장하고 같은 브라우저의 계정 간 공유한다. 다른 브라우저나 저장된 선택이 없으면 모두 켜진 상태로 시작한다. 홈 표시와 조회 규칙은 §6.7을 따른다.
- 설정 화면에서 실험실 기능을 켜거나 끄며, 선택은 기기에 저장한다.
- 실험실 기능이 켜진 경우에만 실험실 설정(`/settings/lab`)으로 이동할 수 있다. 실험실 화면의 뒤로가기는 `/settings`로 이동한다.
- 실험실 기능은 변경되거나 제거될 수 있다.
- 서비스 안내에는 도움말(`/support`, §15.11), 오픈소스 라이선스(`/licenses`, §15.7)와 앱 버전(§15.12)을 둔다. 도움말과 라이선스 화면에서 뒤로 가면 `/settings`로 돌아온다.
- 설정 화면에는 관리 영역이나 관리자 페이지 버튼을 두지 않는다. 관리자 진입점은 §15.1에서 정의한다.
- 이전 `/menu/settings`, `/noti/settings`, `/menu/settings/lab`, `/menu/password`, `/menu/licenses` 주소는 제거하며 호환 리다이렉트를 제공하지 않는다.
- 설정 화면 맨 아래에 로그아웃을 따로 둔다. 로그아웃은 데스크톱 아바타 드롭다운에서도 제공하며, 어느 진입점에서든 확인 후 실행한다.

### 15.4 실험실: 게시물 보기

- 사용자는 카드 보기 또는 목록 보기를 선택한다.
- 선택은 기기에 저장하고 홈 피드와 그룹 게시물 목록에 함께 적용한다.

### 15.5 실험실: 테마

시스템 설정 따르기, 라이트, 다크 중에서 화면 테마를 선택한다.

### 15.7 오픈소스 라이선스

- 서비스에서 사용하는 오픈소스 및 이미지 자산의 저작권 정보를 표시한다.
- 프로젝트 및 라이선스 원문으로 이동할 수 있다.

### 15.11 도움말

- 자주 묻는 질문을 주제별로 묶어 보여준다.
- 각 질문은 접힌 상태로 시작하고 사용자가 펼쳐서 답을 읽는다. 여러 질문을 동시에 펼칠 수 있다.
- 화면 맨 아래에 문의 방법을 안내한다. 눌러서 갈 곳이 있으면 링크로, 없으면 글로만 안내한다. 둘 다 없으면 문의 영역 자체를 표시하지 않는다.
- 표시할 질문이 하나도 없으면 빈 상태를 안내한다.
- 내용은 서비스와 함께 배포되며 사용자나 시점에 따라 달라지지 않는다.

### 15.12 앱 버전

앱 버전 카드는 설정 화면(§15.3)에 둔다. 별도의 업데이트 기록 화면은 두지 않는다.

- 지금 쓰는 빌드를 빌드한 날짜(한국 날짜)와 커밋으로 표시한다. 예: `2026.10.09 · 0c3a00a`. 사람이 버전 번호를 매기지 않는다.
- "지금 확인"을 누르면 자동 확인의 간격과 관계없이 새 버전을 바로 확인하고, 최신이면 최신이라고, 확인하지 못하면 연결을 확인하라고 알린다.
- 새 버전이 준비돼 있으면 화면 위 안내(§3.7)와 같은 새로고침을 카드에서도 제공한다. 안내를 넘겨 둔 사용자도 여기서 적용할 수 있다.
- 서비스 워커가 없는 환경에서는 확인 버튼 없이 확인할 수 없다고 표시한다.

### 15.13 학교 사이트 바로가기

- 모바일과 데스크톱 모두 메뉴 홈(`/menu`)의 "학교 사이트" 구역에서 세 사이트에 직접 접근한다: 홈페이지(`https://www.minjok.hs.kr/`), 인트라넷(`https://old.minjok.hs.kr/members/login.php`), 리로스쿨(`https://minjok.riroschool.kr/`). 별도의 "바로가기" 타일은 두지 않는다.
- 데스크톱 전역 헤더 아바타 드롭다운에는 학교 사이트 링크를 제공하지 않는다.
- `/menu/links` 화면과 경로는 제거한다. 이전 주소에 대한 호환 리다이렉트는 제공하지 않는다.
- 각 링크는 앱을 떠나지 않도록 새 탭으로 열고, 앱 안 화면으로 넘어가는 행과 구분되게 외부 링크 표시를 붙인다.
