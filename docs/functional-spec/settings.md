# 메뉴 및 개인 설정

## 15. 메뉴 및 개인 설정

메뉴에서 여는 학교 기능(급식, 생일, 공결 & 병결, 시간표)의 명세는 §17로 옮겼다. §15.6과 §15.8–15.10은 비워 두며 다시 쓰지 않는다.

### 15.1 메뉴 홈

메뉴 최상단에 내 프로필로 가는 계정 카드를 두고, 아래를 네 묶음으로 나눈다.

- 학교: 공강 · 노래방(§17.1, §17.2), 공결 & 병결(재학생만, §17.6), 급식(§17.4)
- 일정: 시간표(§17.7), 생일(§17.5)
- 설정: 비밀번호 변경, 알림 설정, 개인 설정
- 정보: 오픈소스 라이선스

앱 관리자에게는 관리자 페이지로 가는 항목을 추가로 제공한다. 목록 맨 아래에 로그아웃을 둔다.

관리자 페이지에서 가입 승인, 공강 관리자, 앱 관리자를 한 곳에서 관리한다.

### 15.2 알림 설정

- Web Push 전체 설정과 현재 브라우저 권한 상태를 표시한다.
- Web Push를 지원하지 않는 환경에서는 지원하지 않음을 안내하고 켜기 기능을 제공하지 않는다.
- 브라우저 권한이 거절된 상태에서는 권한 요청을 반복하지 않고 브라우저 설정 변경 방법을 안내한다.
- Web Push 전체 설정을 켜면 보통 및 높음 중요도 유형을 기본으로 켠다.
- 전체 설정을 변경하는 동안 진행 상태를 표시하고 중복 조작을 막는다.
- 사용자는 다음 유형별 Web Push를 끌 수 있다.
  - 댓글 · 답글: 내 게시물에 달린 댓글, 내 댓글에 달린 답글
  - 내 타임라인: 다른 사람이 내 타임라인에 남긴 게시물
  - 그룹 운영 소식: 가입 요청과 승인, 역할과 그룹 정책 변경
  - 계정 · 권한: 가입 승인과 관리 권한 변경
  - 학교 기능: 공강 예약 등 학교 부가 기능 소식
- 그룹별로 앱 알림함 수준과 직접 관련 활동 Push를 따로 설정한다. 앱 알림함 수준을 `없음`으로 두면 해당 그룹의 콘텐츠 Push도 함께 끈다.
- 낮음 중요도의 새 그룹 게시물 Push는 앱 알림함 수준이 `전체`인 그룹에서만 켜거나 끌 수 있다.
- 반응은 인앱 전용이므로 Web Push 설정을 제공하지 않는다.
- 현재 설정이 실제로 무엇을 전달하는지 요약해 보여주고, 설정을 바꾸면 즉시 갱신한다.
- Web Push 전체 설정은 이 기기에만, 유형별과 그룹별 설정은 계정의 모든 기기에 적용된다는 점을 각 설정 옆에 표시한다.
- 유형별 Web Push를 끄면 해당 알림이 앱 알림함에는 계속 쌓인다는 점을 안내한다.
- 운영 조치는 Web Push 전체 설정이 켜져 있는 동안 항상 전달되며 유형별 끄기를 제공하지 않는다.

### 15.3 개인 설정과 실험실 기능

- 개인 설정 화면에서 실험실 기능을 켜거나 끄며, 선택은 기기에 저장한다.
- 실험실 기능이 켜진 경우에만 실험실 설정으로 이동할 수 있다.
- 실험실 기능은 변경되거나 제거될 수 있다.

### 15.4 실험실: 게시물 보기

- 사용자는 카드 보기 또는 목록 보기를 선택한다.
- 선택은 기기에 저장하고 홈 피드와 그룹 게시물 목록에 함께 적용한다.

### 15.5 실험실: 테마

시스템 설정 따르기, 라이트, 다크 중에서 화면 테마를 선택한다.

### 15.7 오픈소스 라이선스

- 서비스에서 사용하는 오픈소스 및 이미지 자산의 저작권 정보를 표시한다.
- 프로젝트 및 라이선스 원문으로 이동할 수 있다.
