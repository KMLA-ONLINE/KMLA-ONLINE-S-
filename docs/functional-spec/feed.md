# 홈 통합 피드

## 6. 홈 통합 피드

### 6.1 피드 구성

홈 피드는 다음 게시물을 하나로 묶는다.

- 자신의 타임라인에 작성된 전체 공개 개인 게시물
- 현재 가입한 그룹의 게시물
- 관련 기수 조건을 만족하는 생탐
- 프로필 사진·커버 등록 또는 변경 활동

비공개 개인 게시물은 홈 피드에 표시하지 않는다.

노출 범위는 다음과 같이 정한다.

- 관련 기수는 일반 재학생이면 자신의 `cohort`, 복학생이면 원래 기수와 함께 생활하는 `cohort + 1`이다.
- 생탐은 작성자와 타임라인 당사자가 다른 공개 개인 게시물이다. 작성자가 아니라 타임라인 당사자를 기준으로 판단하며, 보는 사용자와 타임라인 당사자의 관련 기수가 겹치고 성별이 같을 때만 포함한다.
- 성별 판정은 기수와 독립적이다. 복학생의 `cohort + 1` 확장으로 기수가 겹치더라도 성별이 다르면 포함하지 않는다.
- 졸업생에게는 자신의 관련 기수와 현재 승인된 재학생의 기수가 하나 이상 겹칠 때만 생탐을 제공한다. 교사와 관련 기수가 없는 사용자에게는 제공하지 않는다.
- 프로필 사진·커버 활동은 본인에게 표시한다. 활동 당사자가 교사이면 모든 사용자에게, 학생 또는 졸업생이면 성별과 저장된 기수가 모두 같은 사용자에게만 표시한다. 이 활동의 기수 판정에는 복학생 여부를 사용하지 않는다.

정렬과 페이지네이션은 다음과 같다.

- 최신순을 기준으로 하되, 게시 후 6시간 동안 다른 사용자의 최상위 댓글과 반응을 약하게 반영한다.
- 이 6시간 구간에서 생탐은 일반 게시물보다 60분, 프로필 사진·커버 활동은 일반 개인 게시물보다 10분 낮게 배치한다.
- 그룹 내부의 게시물 고정 여부는 홈 피드 정렬에 영향을 주지 않는다.
- 한 번에 20개씩 불러오고 스크롤을 내리면 이전 게시물을 이어서 불러온다.
- 같은 사용자의 개인 게시물은 연속 2개·페이지당 4개, 같은 그룹의 게시물은 연속 3개·페이지당 10개를 원칙으로 한다. 제한된 게시물은 버리지 않고 뒤 페이지로 미루며, 게시물이 부족하면 제한을 완화해 20개를 우선 채운다.
- 첫 페이지를 불러온 시점의 정렬을 같은 피드 탐색 동안 유지한다. 새 게시물과 새 상호작용은 5초 중복 요청 방지 구간이 지난 뒤의 새로고침부터 반영한다.
- 그룹 멤버십, 게시물 공개 범위, 승인 상태, 삭제 여부 등 현재 접근 권한은 피드 탐색 시작 시점의 상태보다 우선한다.

그 밖의 규칙은 다음과 같다.

- 홈 피드에는 서버 읽음 상태를 저장하지 않는다. 새 게시물 점이나 개수 표시는 제공하지 않으며, 열어 본 게시물 ID만 현재 기기에 저장해 목록 보기에서 시각적으로 구분한다.
- 모바일과 태블릿의 터치 입력에서 홈 피드와 그룹 목록·탐색·상세는 화면 최상단에서 아래로 당겨 다시 불러올 수 있다. 데스크톱 마우스·트랙패드 당김은 이 동작을 시작하지 않으며, 입력·다이얼로그와 내부 스크롤 영역의 제스처는 가로채지 않는다.

랭킹 수식, 안정적인 피드 세션, 출처 제한 및 `#업`의 구현 규칙은 [홈 통합 피드 알고리즘](../FEED_ALGORITHM.md)을 따른다.

### 6.2 `#업`

`#업`은 그룹 게시물의 오래된 공지 등을 홈 통합 피드 위쪽에 다시 노출하는 신호다. 그룹 내부 정렬과 개인 게시물에는 적용하지 않는다.

- 실명 또는 운영진 명의의 최상위 댓글을 새로 등록할 때 본문이 정확히 `#업`이면 유효 후보가 된다. 익명 댓글, 답글 및 댓글 수정으로 만든 `#업`은 적용하지 않는다.
- 같은 게시물의 마지막 유효 `#업`부터 1시간 동안은 새 끌어올림을 만들 수 없다.
- 유효 `#업`은 댓글 등록 시점의 변경 불가능한 사건이다. 그 원인 댓글은 작성자와 운영진을 포함해 수정하거나 삭제할 수 없다.
- `#업` 댓글은 화면의 댓글 수에는 포함하지만 일반 댓글 랭킹 보정에는 포함하지 않으며, 게시물의 원래 작성 시각도 바꾸지 않는다.
- `#업`은 게시물을 끌어올리기만 한다. 최근 상호작용으로 이미 더 위에 있는 게시물의 순위를 낮추지 않는다.
- 유효 `#업` 사건을 만든 댓글은 댓글 목록에서 파란색으로 표시하고, 유효하지 않은 `#업` 댓글은 일반 색으로 표시한다.

### 6.3 게시물 보기 방식

카드와 목록 보기는 같은 피드 후보와 순서를 사용하며, 선택은 실험실 설정(§15.4)에서 바꾼다.

#### 카드 보기

- 그룹 게시물은 그룹, 작성자, 작성 시각, 제목, 본문, 이미지 및 첨부 파일을 표시한다.
- 개인 게시물은 작성자, 타임라인 당사자, 작성 시각, 본문, 이미지 및 첨부 파일을 표시한다. 다른 사용자의 타임라인에 작성한 게시물은 `작성자 → 타임라인 당사자` 형태로 표시한다.
- 반응, 댓글 및 공유 기능을 함께 제공한다.
- 긴 본문은 일부만 표시하고 전체 내용을 펼치거나 접을 수 있다.
- 본문과 메타데이터는 미디어 URL 발급을 기다리지 않고 표시한다. 이미지와 프로필 사진·커버 변경 활동은 기존 비율의 자리를 확보하고 URL 발급 중에는 로딩 안내를 표시한다. 아바타는 기존 대체 이미지를 유지한다.
- URL 발급이 일부 실패해도 본문과 성공한 미디어는 유지한다. 실패한 미디어는 실패 안내로 전환하고 ‘이미지 다시 불러오기’로 재시도할 수 있다. URL이 준비되기 전에는 이미지 확대와 첨부 다운로드를 비활성화한다.

#### 목록 보기

- 그룹 게시물은 제목 중심, 개인 게시물은 본문 일부 중심의 간결한 행으로 표시한다.
- 작성자, 게시 대상, 작성 시각, 반응 수 및 댓글 수를 표시한다.
- 사용자가 열어 본 게시물을 시각적으로 구분한다.

게시물 제목이나 목록 행을 선택하면 홈 피드를 배경으로 유지한 채 게시물 상세를 연다. 댓글 버튼도 같은 배경 위에서 데스크톱 모달 또는 모바일 댓글 시트를 열며 그룹·프로필 화면으로 먼저 이동하지 않는다.

### 6.4 오늘의 급식 요약

- 넓은 화면의 홈에서 현재 시간대에 맞는 조식, 중식 또는 석식 메뉴 하나를 표시한다. 저녁 7시부터는 다음 날 조식을 표시한다. 급식 화면(§17.4)이 다음 날로 넘어가는 기준과 같다.
- 날짜는 표시하지 않고 음식은 원본 순서를 유지하며 한 줄에 두 항목씩 표시한다. 급식 콘텐츠 영역을 선택하면 급식 화면(§17.4)으로 이동한다.

### 6.5 오늘의 생일

- 넓은 화면의 홈에서 ‘생일’ 제목 아래에 오늘 생일인 사용자를 한 줄로 표시한다. 아바타 아래에 작은 이름을 놓고, 많으면 가로로 스크롤한다. 제목·아바타·이름을 포함한 콘텐츠 영역을 선택하면 생일 화면(§17.5)으로 이동한다.
- 오늘 생일인 사용자가 없으면 ‘오늘 생일인 사람이 없습니다’를 표시하며, 이 안내도 생일 화면으로 연결한다.
- 생일은 피드 후보나 랭킹에 영향을 주지 않는다.

### 6.6 오늘의 스토리

- 홈 피드 최상단에 스토리를 작성자별 세로 카드로 가로 스크롤 형태로 표시한다. 카드에는 그 작성자의 스토리 미리보기(사진 축소본 또는 글 배경)와 아바타, 이름을 놓는다. 스토리가 여럿이면 카드가 올린 순서대로 5초마다 다음 스토리를 보여 주고, 위쪽의 짧은 막대로 몇 번째인지 표시한다. 마우스를 올렸거나 누르고 있거나 카드가 화면 밖이거나 앱이 가려졌으면 멈추고, 움직임 줄이기 설정이면 돌리지 않는다. 섹션 제목은 두지 않는다.
- 작성자 순서는 자신의 스토리가 맨 앞이고, 재학생 뷰어에게는 그다음에 같은 기수 재학생을, 나머지는 가장 최근 스토리가 새로운 순서로 둔다.
- 스토리를 올릴 수 있는 사용자에게는 맨 앞에 스토리 만들기 카드를 두어 그 자리에서 만든다. 올릴 수 없는 사용자에게 보일 스토리가 없으면 이 영역은 표시하지 않는다.
- 카드를 선택하면 카드에 지금 보이는 스토리부터 화면 전체 뷰어가 그 작성자의 스토리를 올린 순서대로 한 장씩 7초씩 보여 주고, 상단 막대로 남은 시간을 표시한다. 끝나면 다음 작성자로 넘어가고, 마지막 스토리가 끝나면 닫지 않고 멈춘다. 화면 왼쪽을 누르면 이전 장, 나머지를 누르면 다음 장으로 가고, 데스크톱에서는 카드 양옆의 화살표 버튼으로도 넘긴다(넘길 장이 없는 쪽 버튼은 숨긴다). 화면을 옆으로 쓸면 작성자를 건너뛴다. 왼쪽으로 쓸면 다음 작성자의 첫 장, 오른쪽으로 쓸면 이전 작성자의 첫 장으로 간다. 쓰는 동안 이웃 작성자의 카드가 손가락을 따라 들어오고, 짧게 튕겨도 넘어간다. 마지막 작성자에서 더 쓸면 뷰어를 닫고, 첫 작성자에서 되돌리면 그 자리에 머문다. 누르기와 쓸기는 걸린 시간이 아니라 움직인 거리로 구분한다. 화면을 위나 아래로 쓸면 뷰어를 닫는다. 누르고 있거나 메뉴를 연 동안은 멈춘다. 링크가 있으면 하단 버튼으로 새 창에서 연다.
- 뷰어 왼쪽 위 작성자 아바타를 누르면 그 작성자의 프로필로 이동한다. 뒤로 가면 보던 스토리로 돌아온다.
- 뷰어 오른쪽 위 메뉴에서 스토리 링크를 복사하고, 자신의 스토리는 삭제한다. 링크로 들어왔는데 스토리가 만료됐거나 볼 수 없으면 알리고 홈에 머문다.
- 노출은 작성자의 유형으로만 판정하며 기수는 쓰지 않는다. 교사의 스토리는 모든 승인 사용자에게 보이고, 재학생의 스토리는 재학생과 교사에게만 보인다. 졸업생에게는 재학생의 스토리를 노출하지 않는다.
- 올린 지 24시간이 지난 스토리는 노출하지 않는다.
- 레일은 사진 스토리의 축소본(긴 변 640px)만 받고, 원본은 뷰어에서 그 장을 열 때 받는다.

### 6.7 데스크톱 학교생활 요약

- 넓은 화면의 홈 우측 사이드바에는 오늘의 생일(§6.5), 급식 요약(§6.4), 오늘의 개인 시간표 순서로 배치한다. 공강·노래방과 기부물품 버튼은 표시하지 않는다. 다른 페이지에는 이 사이드바를 표시하지 않는다.
- 우측 사이드바는 1024px 이상에서 표시한다. 사이드바가 숨겨지는 768~1023px에서는 홈 피드 위에 학교 기능 바로가기 줄을 표시하지 않는다. 768px 미만의 모바일 홈도 유지하며 기부물품 버튼을 표시하지 않는다. 학교 기능은 모든 너비에서 메뉴 탭(`/menu`)으로 진입한다.
- 설정(§15.3)에서 전체 또는 개별 항목을 끌 수 있다. 켜진 항목만 기존 순서로 표시하고 구분선은 표시되는 항목 사이에만 둔다. 전체가 꺼져 있거나 개별 항목이 모두 꺼져 있으면 사이드바 영역도 제거하고 피드를 기존 데스크톱 피드 열의 최대 너비로 중앙 정렬한다.
- 1024px 미만에서는 저장된 선택과 관계없이 홈 생일·급식·시간표 요약용 요청을 시작하지 않는다. 1024px 이상에서도 꺼진 항목은 조회하지 않는다. 화면을 넓히면 활성 항목을 불러오되 기존 피드 세션은 유지한다. 이미 시작한 요청·캐시는 취소하거나 삭제하지 않으며 별도 생일·급식·시간표 화면의 조회에는 영향을 주지 않는다.
- 피드와 우측 사이드바 사이에는 24px 간격을 둔다.
- 기존 홈 콘텐츠 폭과 열 비율을 유지하며 사이드바도 페이지와 함께 스크롤한다. 각 영역의 상시 바깥 카드 테두리·그림자는 두지 않고, 호버 배경에는 공통 기본 둥글기를 적용한다. 영역 사이 구분선과 시간표 격자선은 유지한다. 구분선 위아래 간격은 각각 12px, 콘텐츠 영역 패딩은 네 방향 모두 8px로 두어 콘텐츠 사이 세로 거리는 유지하면서 호버·클릭 영역을 넓히고 좌우 콘텐츠 폭을 줄인다.
- 각 영역의 ‘오늘의 …’ 제목과 전체 보기 버튼은 표시하지 않는다. 대신 콘텐츠 전체를 해당 기능 페이지로 연결하며, 키보드로도 링크를 선택할 수 있다.
- 생일과 급식은 독립적으로 불러와 준비된 영역부터 표시한다. 로딩 중에는 실제 배치에 맞춘 생일 아바타·이름과 2열 급식 메뉴 스켈레톤을 표시한다. 생일 영역의 최소 높이는 제목과 빈 상태 안내에 맞추며, 생일 인원이 있거나 로딩 중일 때는 콘텐츠만큼 늘어난다. 빈 결과가 도착할 때 영역이 줄어드는 것은 허용한다. 급식은 빈 상태·실패 상태에서도 메뉴 기준 최소 높이를 유지해 아래 콘텐츠의 이동을 줄이며, 메뉴는 생략하거나 내부 스크롤로 제한하지 않고 길이에 따라 영역을 늘려 모두 표시한다.
- 생일·급식 요청이 실패해도 영역을 숨기지 않고 실패 안내와 잠시 후 다시 확인하라는 문구를 표시한다. 실패 안내도 해당 기능 화면으로 연결한다.
- 데스크톱 전역 헤더에는 공강·노래방 버튼을 표시하지 않는다. 메뉴 화면의 공강·노래방과 기부물품 바로가기, 모바일 홈의 급식 버튼과 메뉴 탭은 유지한다.
- 오늘의 시간표는 선택 중인 학기의 본인 시간표를 날짜 없이 읽기 전용으로 표시한다. 다른 요약 영역과 같이 포인터를 올리면 배경이 어두워진다. 평일에는 교시·시작 시간·수업과 장소를 1~8교시 격자로 표시하며 빈 교시는 빈칸으로 둔다. 하루 전체가 비어 있어도 격자는 유지한다.
- 토요일과 일요일에는 격자 대신 ‘주말에는 시간표가 없습니다’를 표시한다. 시간표 콘텐츠 영역은 빈 격자·주말 안내를 포함해 기존 시간표 화면(§17.7)으로 연결하며, 편집은 해당 화면에서 한다.
- 시간표는 생일·급식과 독립적으로 불러오며 기기에 저장된 시간표가 있으면 먼저 표시한다. 평일에 저장된 시간표가 없고 요청 중이면 실제 교시 행·시간 열과 같은 크기의 8교시 격자 스켈레톤을 표시한다. 주말 안내에는 평일 격자의 높이를 강제하지 않는다.
