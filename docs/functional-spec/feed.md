# 홈 통합 피드

## 6. 홈 통합 피드

### 6.1 피드 구성

홈 피드는 다음 게시물을 하나로 묶는다.

- 자신의 타임라인에 작성된 전체 공개 개인 게시물
- 현재 가입한 그룹의 게시물
- 관련 기수 조건을 만족하는 생탐
- 프로필 사진·커버 등록 또는 변경 활동

비공개 개인 게시물은 홈 피드에 표시하지 않는다.

노출 범위는 다음과 같이 정한다.

- 관련 기수는 일반 재학생이면 자신의 `cohort`, 복학생이면 원래 기수와 함께 생활하는 `cohort + 1`이다.
- 생탐은 작성자와 타임라인 당사자가 다른 공개 개인 게시물이다. 작성자가 아니라 타임라인 당사자를 기준으로 판단하며, 보는 사용자와 타임라인 당사자의 관련 기수가 겹치고 성별이 같을 때만 포함한다.
- 성별 판정은 기수와 독립적이다. 복학생의 `cohort + 1` 확장으로 기수가 겹치더라도 성별이 다르면 포함하지 않는다.
- 졸업생에게는 자신의 관련 기수와 현재 승인된 재학생의 기수가 하나 이상 겹칠 때만 생탐을 제공한다. 교사와 관련 기수가 없는 사용자에게는 제공하지 않는다.
- 프로필 사진·커버 활동은 본인에게 표시한다. 활동 당사자가 교사이면 모든 사용자에게, 학생 또는 졸업생이면 성별과 저장된 기수가 모두 같은 사용자에게만 표시한다. 이 활동의 기수 판정에는 복학생 여부를 사용하지 않는다.

정렬과 페이지네이션은 다음과 같다.

- 최신순을 기준으로 하되, 게시 후 6시간 동안 다른 사용자의 최상위 댓글과 반응을 약하게 반영한다.
- 이 6시간 구간에서 생탐은 일반 게시물보다 60분, 프로필 사진·커버 활동은 일반 개인 게시물보다 10분 낮게 배치한다.
- 그룹 내부의 게시물 고정 여부는 홈 피드 정렬에 영향을 주지 않는다.
- 한 번에 20개씩 불러오고 스크롤을 내리면 이전 게시물을 이어서 불러온다.
- 같은 사용자의 개인 게시물은 연속 2개·페이지당 4개, 같은 그룹의 게시물은 연속 3개·페이지당 10개를 원칙으로 한다. 제한된 게시물은 버리지 않고 뒤 페이지로 미루며, 게시물이 부족하면 제한을 완화해 20개를 우선 채운다.
- 첫 페이지를 불러온 시점의 정렬을 같은 피드 탐색 동안 유지한다. 새 게시물과 새 상호작용은 5초 중복 요청 방지 구간이 지난 뒤의 새로고침부터 반영한다.
- 그룹 멤버십, 게시물 공개 범위, 승인 상태, 삭제 여부 등 현재 접근 권한은 피드 탐색 시작 시점의 상태보다 우선한다.

그 밖의 규칙은 다음과 같다.

- 홈 피드에는 서버 읽음 상태를 저장하지 않는다. 새 게시물 점이나 개수 표시는 제공하지 않으며, 열어 본 게시물 ID만 현재 기기에 저장해 목록 보기에서 시각적으로 구분한다.
- 모바일과 태블릿의 터치 입력에서 홈 피드와 그룹 목록·탐색·상세는 화면 최상단에서 아래로 당겨 다시 불러올 수 있다. 데스크톱 마우스·트랙패드 당김은 이 동작을 시작하지 않으며, 입력·다이얼로그와 내부 스크롤 영역의 제스처는 가로채지 않는다.

랭킹 수식, 안정적인 피드 세션, 출처 제한 및 `#업`의 구현 규칙은 [홈 통합 피드 알고리즘](../FEED_ALGORITHM.md)을 따른다.

### 6.2 `#업`

`#업`은 그룹 게시물의 오래된 공지 등을 홈 통합 피드 위쪽에 다시 노출하는 신호다. 그룹 내부 정렬과 개인 게시물에는 적용하지 않는다.

- 실명 또는 운영진 명의의 최상위 댓글을 새로 등록할 때 본문이 정확히 `#업`이면 유효 후보가 된다. 익명 댓글, 답글 및 댓글 수정으로 만든 `#업`은 적용하지 않는다.
- 같은 게시물의 마지막 유효 `#업`부터 1시간 동안은 새 끌어올림을 만들 수 없다.
- 유효 `#업`은 댓글 등록 시점의 변경 불가능한 사건이다. 그 원인 댓글은 작성자와 운영진을 포함해 수정하거나 삭제할 수 없다.
- `#업` 댓글은 화면의 댓글 수에는 포함하지만 일반 댓글 랭킹 보정에는 포함하지 않으며, 게시물의 원래 작성 시각도 바꾸지 않는다.
- `#업`은 게시물을 끌어올리기만 한다. 최근 상호작용으로 이미 더 위에 있는 게시물의 순위를 낮추지 않는다.
- 유효 `#업` 사건을 만든 댓글은 댓글 목록에서 파란색으로 표시하고, 유효하지 않은 `#업` 댓글은 일반 색으로 표시한다.

### 6.3 게시물 보기 방식

카드와 목록 보기는 같은 피드 후보와 순서를 사용하며, 선택은 실험실 설정(§15.4)에서 바꾼다.

#### 카드 보기

- 그룹 게시물은 그룹, 작성자, 작성 시각, 제목, 본문, 이미지 및 첨부 파일을 표시한다.
- 개인 게시물은 작성자, 타임라인 당사자, 작성 시각, 본문, 이미지 및 첨부 파일을 표시한다. 다른 사용자의 타임라인에 작성한 게시물은 `작성자 → 타임라인 당사자` 형태로 표시한다.
- 반응, 댓글 및 공유 기능을 함께 제공한다.
- 긴 본문은 일부만 표시하고 전체 내용을 펼치거나 접을 수 있다.

#### 목록 보기

- 그룹 게시물은 제목 중심, 개인 게시물은 본문 일부 중심의 간결한 행으로 표시한다.
- 작성자, 게시 대상, 작성 시각, 반응 수 및 댓글 수를 표시한다.
- 사용자가 열어 본 게시물을 시각적으로 구분한다.

게시물 제목이나 목록 행을 선택하면 홈 피드를 배경으로 유지한 채 게시물 상세를 연다. 댓글 버튼도 같은 배경 위에서 데스크톱 모달 또는 모바일 댓글 시트를 열며 그룹·프로필 화면으로 먼저 이동하지 않는다.

### 6.4 오늘의 급식 요약

- 넓은 화면의 홈에서 오늘 날짜와 현재 시간대에 맞는 조식, 중식 또는 석식 메뉴 하나를 표시한다.
- 요약을 선택하면 급식 화면(§17.4)으로 이동한다.

### 6.5 오늘의 생일

- 넓은 화면의 홈에서 오늘 생일인 사용자를 표시하고, 선택하면 해당 프로필 또는 생일 화면(§17.5)으로 이동한다.
- 오늘 생일인 사용자가 없으면 이 영역은 표시하지 않는다.
- 생일은 피드 후보나 랭킹에 영향을 주지 않는다.

### 6.6 오늘의 스토리

- 홈 피드 최상단에 오늘의 스토리를 가로 스크롤 형태로 표시한다. 오늘 노출할 기록이 없으면 이 영역은 표시하지 않는다.
- 작성과 수정은 메뉴의 스토리 화면(§17.6)에서 한다.
- 내용은 공백 제거 후 2자 이상 100자 이하다.
- 노출은 작성자의 유형으로만 판정하며 기수는 쓰지 않는다. 교사의 스토리는 모든 승인 사용자에게 보이고, 재학생의 스토리는 재학생과 교사에게만 보인다. 졸업생에게는 재학생의 스토리를 노출하지 않는다.
- 같은 날 다시 작성하면 자신의 기존 당일 기록을 새 내용으로 교체하며, 자신의 당일 기록은 수정하거나 삭제할 수 있다.
- 한국 시간 기준 당일 기록만 조회하며 전날 기록은 노출하지 않는다.
