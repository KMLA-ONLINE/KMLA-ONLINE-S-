# 게시물 및 상호작용

## 8. 게시물

### 8.1 게시물 종류와 공통 기능

- 게시물은 단일 게시물 구조에서 `그룹` 또는 `개인` 종류로 구분한다.
- 두 종류는 공통 게시물 ID, 본문, 작성자, 댓글, 답글, 반응 및 첨부 기능을 사용한다.
- 그룹 게시물에는 그룹, 제목, 카테고리, 작성 신원 및 고정 상태를 둔다.
- 개인 게시물에는 타임라인 당사자와 공개 범위를 두며 제목, 카테고리, 익명, 운영진 명의 및 고정 상태를 사용하지 않는다.

### 8.2 그룹 게시물 작성 권한

- 모든 멤버 작성 그룹에서는 모든 멤버가 게시물을 작성할 수 있다.
- 운영진 작성 그룹에서는 소유자, 관리자 및 매니저만 게시물을 작성할 수 있다.
- 운영진 작성 그룹에서도 모든 멤버가 댓글과 반응을 남길 수 있다.

### 8.3 게시물 작성

모든 게시물 작성자는 다음 항목을 입력하거나 선택한다.

- 본문
- 사진
- 일반 파일

그룹 게시물 작성자는 다음 항목을 추가로 입력하거나 선택한다.

- 작성 신원
- 제목
- 카테고리

그룹 게시물의 제목은 필수다. 카테고리는 그룹에 카테고리가 있더라도 선택 사항이며, 선택하지 않은 게시물은 미분류로 표시한다. 제목 외에는 본문 또는 업로드 준비가 끝난 첨부가 하나 이상 있어야 게시할 수 있으므로 제목만 있는 게시물은 허용하지 않는다.

데스크톱 본문 편집기는 입력 중인 본문에 서식을 즉시 표시하며 다음 기능을 제공한다.

- 굵게
- 기울임
- 취소선
- 큰 제목과 작은 제목
- HTTP(S) 링크
- 실행 취소와 다시 실행
- 굵게 `Ctrl/Cmd+B`, 기울임 `Ctrl/Cmd+I`, 취소선 `Ctrl/Cmd+Shift+X` 단축키
- 편집 중인 링크를 `Ctrl/Cmd+클릭`해 열기

별도 미리보기 화면은 제공하지 않는다. 편집기와 게시물 출력은 같은 본문 타이포그래피 규칙을 사용한다.

모바일에서는 서식 도구 없이 일반 텍스트 본문 입력만 제공한다. 제목, 카테고리, 작성 신원, 공개 범위, 사진과 파일 첨부 및 게시 기능은 데스크톱과 동일하게 제공한다.

작성자는 본문 글꼴, 임의 글자 크기, 글자색 및 배경색을 지정할 수 없다.

첨부 기능은 다음과 같다.

- 사진 및 파일 다중 선택
- 데스크톱 파일 끌어놓기
- 사진 미리보기
- 첨부 파일 개별 제거
- 게시물 하나당 최대 10개 첨부
- 정규화된 사진은 파일당 최대 8MiB다.
- 비이미지 파일은 형식과 관계없이 첨부할 수 있으며 파일당 최대 30MiB다.
- 사진 이외의 파일은 미리보기 없이 다운로드로만 제공한다.

그룹 게시물 제목은 최대 100자다. 모든 게시물 본문은 최대 20,000자다.

### 8.4 개인 게시물 작성

- 승인 사용자는 자신의 타임라인에 개인 게시물을 작성할 수 있다.
- 프로필 당사자가 타인 작성을 허용한 경우 다른 승인 사용자가 해당 타임라인에 개인 게시물을 작성할 수 있다.
- 타인 작성 허용은 기본값이 `허용`이며 프로필 당사자가 언제든 끌 수 있다.
- 타인 작성을 끄면 새 타인 게시물만 차단하고 기존 게시물은 유지한다.
- 다른 사용자의 타임라인에 작성한 게시물은 즉시 전체 공개한다.
- 자신의 타임라인에 작성한 게시물은 `전체 공개` 또는 `비공개`를 선택할 수 있다.
- 작성자는 자신의 타임라인 게시물 공개 범위를 게시 후에도 변경할 수 있다.
- 비공개 게시물은 작성자 본인만 볼 수 있으며 홈 피드, 전역 검색, 멘션 및 알림에서 제외한다.
- 전체 공개 개인 게시물은 승인 사용자 전체가 볼 수 있지만 전역 게시물 검색과 사용자 멘션은 지원하지 않는다.
- 개인 게시물과 그 댓글은 항상 실명으로 작성한다.
- 프로필 미디어 등록·변경 활동은 전체 공개 개인 게시물의 하위 유형이다. 본문과 일반 첨부를 사용하지 않고 변경 당시 이미지 하나를 표시하며 수정할 수 없고, 프로필 타임라인과 홈 통합 피드에 모두 포함한다.
- 프로필 미디어 활동의 댓글, 반응, 공유 및 작성자 삭제는 일반 개인 게시물과 동일하게 동작한다.

### 8.5 그룹 활동 신원 정책

#### 실명만

- 모든 게시물과 댓글은 실제 프로필로 작성한다.
- 반응 참여자도 실제 프로필로 표시한다.

#### 작성할 때 선택

- 게시물과 댓글을 실명 또는 익명으로 작성할 수 있다.
- 반응은 실명으로 남는다.

게시 시 선택한 실명 또는 익명 상태는 이후 변경할 수 없다.

### 8.6 그룹 운영진 명의

- 그룹 소유자, 관리자 및 매니저는 모든 그룹에서 개인 이름 대신 `운영진`으로 게시물이나 댓글을 작성할 수 있다.
- 운영진 명의는 작성할 때 선택하며 자동으로 적용하지 않는다.
- 운영진 명의 게시물은 그룹 화면, 게시물 상세 및 홈 통합 피드에서 모두 실제 작성자의 프로필 사진과 이름을 표시한다. 그룹 화면과 게시물 상세에서는 이름 옆에 무채색 운영진 배지를 표시하고, 홈 통합 피드에서는 배지를 생략한다.
- 실명 및 운영진 명의 게시물의 작성자 사진이나 이름에서 작성자 프로필로 이동할 수 있다. 익명 게시물은 프로필 이동을 제공하지 않는다.
- 실명 전용 그룹에서는 실명 또는 `운영진`, 선택 익명 그룹에서는 실명·익명 또는 `운영진` 명의를 선택할 수 있다.
- 일반 멤버는 `운영진` 명의를 사용할 수 없다.

### 8.7 그룹 게시물 목록

그룹 게시물 탭은 다음 기능을 제공한다.

- 고정 게시물을 상단에 표시
- 나머지 게시물을 최신순으로 표시
- 전체 또는 카테고리별 필터
- 카드 또는 목록 보기 전환
- 이전 게시물 추가 불러오기

카드 또는 목록 보기 선택은 현재 기기의 모든 그룹에서 공통으로 유지한다. 여러 고정 게시물은 고정한 시각이 아니라 게시 시각이 최신인 순서로 표시한다.

그룹 게시물 목록과 홈 통합 피드의 목록 보기에서는 사용자가 열어 본 게시물을 시각적으로 구분한다. 방문한 게시물 ID는 현재 기기의 로컬 상태에만 저장하고 기기 간 동기화하거나 서버 읽음 상태로 만들지 않는다.

### 8.8 게시물 상세

게시물 상세에는 다음 정보를 표시한다.

- 게시물 종류와 게시 대상
- 그룹 게시물의 그룹, 카테고리 및 고정 여부
- 그룹 게시물의 작성자 또는 익명·운영진 표시
- 개인 게시물의 작성자와 타임라인 당사자
- 작성 시각. 게시물에는 수정 표시를 두지 않는다
- 그룹 게시물의 제목과 모든 게시물의 전체 본문
- 이미지와 첨부 파일
- 반응 수와 댓글 수
- 반응, 댓글 및 공유 기능
- 댓글과 답글 목록

피드 카드의 댓글 버튼은 데스크톱에서 게시물 상세를 열고 댓글 입력창에 포커스를 주며, 모바일에서는 게시물 본문 없이 댓글과 답글 목록 및 입력창만 담은 화면 높이 95%의 하단 시트를 열되 입력창에 자동 포커스를 주지 않는다. 모바일 키보드가 열리면 하단 시트는 키보드 위의 보이는 화면 안에서 줄어들며, 문서나 시트 전체가 아니라 댓글 목록만 스크롤한다. 제목, 검색 결과, 공유 링크 및 직접 상세 주소로 진입하면 모바일에서도 전체 게시물 상세를 열며 댓글 입력창에 자동 포커스를 주지 않는다.

- 이 항목에서 1024px 이하이고 터치가 주 입력인 모바일과 태블릿은 댓글 하단 시트를 사용하며 자동 포커스를 주지 않는다. 일반 컴퓨터는 창 폭과 관계없이 게시물 상세 모달과 자동 포커스 동작을 유지한다. 모바일 시트는 전체 폭을 쓰고, 태블릿 시트는 최대 2xl 폭으로 화면 가로 중앙에 둔다.

### 8.9 그룹 게시물 검색

- 검색 입력창은 기본적으로 숨기고 검색 아이콘을 누르면 펼친다.
- 입력만으로 검색하지 않으며 한글 조합이 끝난 뒤 `Enter` 또는 검색 버튼으로 제출한다.
- 검색을 닫으면 검색어와 결과를 지우고 현재 카테고리의 게시물 목록으로 돌아간다. 새로 열 때는 언제나 빈 검색어로 시작한다.
- 열린 검색 화면과 제출한 검색어는 주소에 남긴다. 뒤로가기는 그룹을 떠나지 않고 검색만 닫으며, 검색어를 여러 번 바꿔도 뒤로가기 한 번이면 그룹 화면으로 돌아온다.
- 그룹 안에서 게시물 제목과 본문을 검색한다.
- 대소문자와 공백 차이를 무시한 부분 일치를 지원한다.
- 최신 게시물부터 최대 50개 결과를 제공한다.
- 결과에 카테고리, 제목, 본문 일부, 작성자 및 작성 시각을 표시한다.
- 결과를 선택하면 게시물 상세로 이동하고, 거기서 뒤로가기로 돌아오면 같은 검색 결과를 다시 보여준다.
- 개인 게시물은 전체 공개 여부와 관계없이 전역 및 그룹 게시물 검색 결과에 포함하지 않는다.

### 8.10 게시물 수정

게시물 작성자는 다음 항목을 수정할 수 있다.

- 본문
- 기존 첨부 제거
- 새 첨부 추가

그룹 게시물 작성자는 제목과 카테고리도 수정할 수 있다. 자신의 타임라인에 작성한 개인 게시물의 작성자는 전체 공개와 비공개를 변경할 수 있다.

새 그룹 게시물을 익명 또는 운영진 명의로 작성할 때는 게시 전에 작성 신원을 확인한다.

새 게시물 작성 화면은 본문 또는 첨부가 있는 상태에서 나가려 할 때 저장하지 않은 초안을 확인한다. 게시물 수정 화면은 제목, 본문, 카테고리 또는 첨부 중 하나라도 원본과 달라진 상태에서 나가려 할 때 저장하지 않은 변경 사항을 확인한다.

작성 시 선택한 익명 여부 또는 운영진 명의는 수정할 수 없다.

### 8.11 그룹 게시물 고정

- 소유자, 관리자 및 매니저는 게시물을 고정하거나 고정을 해제할 수 있다.
- 고정 게시물은 그룹 피드의 첫 페이지 상단에 표시한다.
- 고정 상태는 홈 통합 피드 정렬에는 영향을 주지 않는다.

### 8.12 게시물 삭제

- 작성자는 자신의 게시물을 삭제할 수 있다.
- 그룹 소유자와 관리자는 그룹 안의 다른 멤버 게시물을 삭제할 수 있다.
- 개인 게시물의 타임라인 당사자는 다른 사용자가 자신의 타임라인에 작성한 게시물을 삭제할 수 있다.
- 개인 게시물은 작성자와 타임라인 당사자 이외의 사용자가 삭제할 수 없다.
- 삭제된 게시물의 첨부와 반응은 함께 제거된다.
- 그룹 운영자가 타인의 게시물을 삭제하면 작성자에게 운영 조치 알림을 보낸다.
- 운영자의 신원은 삭제 알림에 표시하지 않는다.
- 타임라인 당사자가 다른 사용자의 개인 게시물을 삭제하면 작성자에게 삭제 알림을 보낸다.

### 8.13 게시물 공유

- 공유 기능을 지원하는 기기에서는 운영체제 공유 화면을 연다.
- 그 외 환경에서는 게시물 링크를 클립보드에 복사한다.

### 8.14 그룹 게시물 사용자 멘션

- 게시물 또는 댓글 작성자가 같은 그룹의 멤버를 선택해 멘션할 수 있다.
- 게시물 또는 댓글 하나에 최대 10명을 멘션할 수 있다.
- 같은 멘션을 제거한 뒤 다시 추가해도 동일한 알림을 반복해서 보내지 않는다.
- 개인 게시물과 그 댓글에서는 사용자 멘션을 지원하지 않는다.

### 8.15 그룹 게시물 신고

- 그룹에 가입한 멤버는 해당 그룹의 그룹 게시물을 신고할 수 있다. 개인 게시물 신고는 이 범위에 포함하지 않는다.
- 자신의 게시물은 신고할 수 없다.
- 한 사용자는 같은 게시물을 한 번만 신고할 수 있다.
- 신고 사유는 `욕설·비방·괴롭힘`, `음란하거나 부적절한 콘텐츠`, `개인정보 침해`, `사칭·허위 정보`, `스팸·광고`, `기타` 중 하나를 선택한다.
- 설명은 입력하는 경우 5자 이상 300자 이하이며, `기타`를 선택하면 필수다.
- 신고자 신원은 신고 목록 및 조회 응답에 포함하지 않는다.
- 소유자, 관리자 및 매니저는 그룹의 신고 탭을 볼 수 있다.
- 신고 목록은 게시물 단위로 묶어 총 신고 수, 사유별 신고 수 및 최근 신고 시각을 표시하고 신고 수 또는 최근순으로 정렬할 수 있다.
- 신고 목록은 일정 개수씩 커서 기반으로 불러오며 목록 하단에 도달하면 다음 페이지를 이어서 불러온다.
- 사유별 집계는 목록 페이지 단위의 단일 조회에서 계산하며 게시물마다 별도 집계 요청을 하지 않는다.
- 설명 목록은 최초 신고 목록 조회에 포함하지 않는다. 사용자가 해당 게시물의 설명을 열었을 때 별도 페이지로 불러오고 추가 설명은 이어서 불러온다.
- 매니저는 신고 내용을 조회만 할 수 있다. 신고 탭의 게시물 삭제 및 신고 무시 동선은 그룹 소유자와 관리자에게만 제공한다. 작성자의 일반 게시물 삭제 권한은 §8.12를 따른다.
- 소유자와 관리자는 신고를 무시해 해당 게시물을 신고 탭에서 내릴 수 있다. 무시는 확인 단계를 거친다.
- 무시는 신고 기록을 삭제하지 않는다. 무시한 시각까지의 신고만 처리한 것으로 표시하며, 이후 새로운 신고가 들어오면 해당 게시물이 신고 탭에 다시 나타난다.
- 다시 나타난 게시물의 총 신고 수, 사유별 신고 수, 최근 신고 시각 및 설명 목록은 마지막 무시 이후의 신고만 반영한다. 그 전에 무시한 신고 건수는 별도 값으로 함께 표시한다.
- 항상 익명 그룹에서는 신고 목록에서도 작성자 이름, 프로필 사진, 프로필 링크 및 실제 작성자를 식별할 수 있는 값을 반환하거나 표시하지 않는다.
- 항상 익명이 아닌 그룹에서도 기존 그룹 작성 신원 정책에 따라 실명, 익명 및 운영진 표시를 적용한다.
- 게시물이 삭제되면 해당 게시물의 신고 기록도 함께 제거한다.
- 신고 알림은 제공하지 않는다.

### 8.16 게시물 구현 단계

다음 단계는 기능 요구를 축소하지 않고 구현과 검증의 전달 경계를 나누기 위한 것이다.

1. 카테고리 관리, 텍스트 게시물 작성·조회·수정·삭제, 작성 신원과 권한, 목록·상세·검색·고정·공유 및 반응형 route 화면을 구현한다.
2. Markdown v1 안전 렌더링과 데스크톱 Milkdown WYSIWYG 편집기를 구현한다. 모바일은 네이티브 `textarea`를 유지한다.
3. 사진·파일 첨부, private Storage 접근, 이미지 정규화, 업로드 상태 전이, signed URL 및 고아 object 정리를 구현한다.

그룹 게시물과 개인 게시물은 모두 실제 데이터에 연결되어 있다. 댓글과 답글, 게시물과 댓글의 반응, 첨부도 두 종류가 함께 쓴다.

홈 통합 피드 연결은 후속 범위다. 게시물 사용자 멘션, 운영자가 타인의 게시물이나 댓글을 삭제할 때 보내는 알림, 그리고 타임라인 당사자가 타인의 개인 게시물을 삭제할 때 보내는 알림은 각각의 후속 기능에서 구현한다.

## 9. 댓글 및 답글

### 9.1 댓글 작성

- 그룹 게시물에는 해당 게시물에 접근할 수 있는 그룹 멤버가 댓글을 작성한다.
- 전체 공개 개인 게시물에는 승인 사용자가 댓글을 작성할 수 있다.
- 비공개 개인 게시물에는 작성자 본인만 댓글을 작성할 수 있다.
- `Enter`로 댓글을 등록하고 `Shift+Enter`로 줄을 바꿀 수 있다.
- 선택 익명 그룹에서는 실명 또는 익명 신원을 선택할 수 있다.
- 그룹 소유자, 관리자 및 매니저는 운영진 명의를 선택할 수 있다.
- 개인 게시물 댓글은 항상 실명으로 작성한다.
- 모든 그룹 및 개인 게시물의 댓글과 답글에는 이미지를 하나까지 첨부할 수 있다. 본문 또는 이미지 중 하나는 반드시 있어야 한다.
- 댓글 본문은 최대 5,000자다.
- 댓글 본문은 평문이며 서식을 지원하지 않는다. 줄바꿈과 링크, 이모지만 그대로 표시한다.
- 이미지 선택기와 붙여넣기를 지원하고 데스크톱에서는 끌어놓기도 지원한다. 작성 중 인라인 미리보기에서 이미지를 제거하거나 교체할 수 있다.
- 댓글 이미지는 JPEG, PNG 또는 WebP 입력을 긴 변 최대 3072px, 최대 8MiB의 WebP로 정규화한다.
- 등록된 이미지는 댓글 안에서 미리 보고, 선택하면 기존 이미지 뷰어에서 보거나 이미지 UUID에 `.webp`를 붙인 이름으로 다운로드한다. 원본 파일 이름은 저장하거나 표시하지 않는다.
- 작성 신원은 입력창에서 고르며, 바꾸기 직전에 결과를 알리고 확인을 받는다. 등록에는 별도 확인 단계를 두지 않는다.
- 선택한 작성 신원은 게시물을 보는 동안 유지하며 다음 댓글에도 이어 쓴다. 작성 신원 변경 전후에도 입력한 본문과 선택한 이미지는 유지한다.
- 최상위 댓글은 가장 오래된 댓글부터 작성 순서대로 표시한다. 첫 페이지 이후의 더 최신 댓글은 목록 하단의 `댓글 더 보기`로 이어 불러온다.

### 9.2 답글

- 댓글에 답글을 작성할 수 있다.
- 답글은 최대 10단계까지 중첩할 수 있다.
- 답글에 부모 댓글 작성자를 표시한다.
- 부모 댓글 표시를 선택하면 원래 댓글 위치로 이동하고 강조한다. 이동은 댓글 목록 안에서만 일어나며 게시물 상세나 댓글 시트 자체는 움직이지 않는다.
- 최상위 댓글별로 답글 수를 표시하고 답글 묶음을 펼치거나 접을 수 있다.
- 답글 묶음은 펼칠 때 불러오며 한 번 불러온 뒤에는 접었다 펴도 다시 불러오지 않는다.
- 화면 들여쓰기는 최상위와 답글 한 단계까지만 적용한다. 3단계 이상의 답글은 1단계와 같은 위치에 작성 시각 순으로 표시하고 부모 댓글 작성자를 함께 밝힌다.
- 답글은 화면 하단의 공용 댓글 입력창에서 작성한다. 답글을 선택하면 대상 댓글을 잠시 강조하고 입력창에 포커스를 주며, 입력창 위의 대상 표시와 취소 버튼으로 현재 답글 대상을 밝힌다. 키보드가 열리며 대상 댓글이 가려지면 댓글 목록을 필요한 거리만큼만 스크롤해 다시 보이게 한다. 작성 중인 본문과 이미지는 답글 대상을 선택하거나 취소해도 유지한다.
- 부모 댓글이 삭제되어도 부모 표시는 남긴다. 지우면 답글이 최상위 댓글처럼 보여 누구에게 한 말인지 사라지고, 엉뚱한 사람에게 한 말로 읽힌다.
- 답글 수에는 삭제된 댓글을 세지 않는다.

### 9.3 댓글 작성자 이름

- 게시물 작성자가 실명 또는 운영진 명의로 자신의 게시물에 댓글을 남기면 이름 옆에 `작성자`를 표시한다.
- 게시물과 댓글의 신원이 다르면 `작성자`를 표시하지 않는다. 익명 게시물의 글쓴이는 아래의 `글쓴이` 이름이 밝히고, 실명 게시물에 남긴 익명 댓글에 표시를 붙이면 익명이 벗겨진다.
- 익명 게시물 작성자가 익명 댓글을 남기면 `글쓴이`로 표시할 수 있다.
- 다른 익명 참여자는 게시물 안에서 `익명1`, `익명2`와 같이 구분한다.
- 익명 번호는 게시물 단위로만 유지하며 다른 게시물의 동일 사용자와 연결하지 않는다.

### 9.4 댓글 수정 및 삭제

- 댓글 작성자는 자신의 댓글 본문을 수정하고 이미지를 추가, 제거 또는 교체할 수 있다. 수정 후에도 본문 또는 이미지 중 하나는 있어야 하며 이미지 변경도 수정 표시에 반영한다.
- 댓글 작성자는 자신의 댓글을 삭제할 수 있다.
- 그룹 소유자와 관리자는 해당 그룹 게시물의 타인 댓글을 삭제할 수 있다.
- 최상위 댓글을 삭제하면 그 아래 답글 전체를 함께 숨긴다.
- 중간 답글을 삭제하고 하위 답글이 남아 있으면 `삭제된 댓글입니다` 표시를 유지해 대화 연결을 보존한다.
- 삭제된 답글은 그 아래에 삭제되지 않은 답글이 하나라도 남아 있는 동안만 `삭제된 댓글입니다`로 표시한다. 마지막 하위 답글이 삭제되면 표시도 함께 사라진다.
- `삭제된 댓글입니다` 표시에는 본문과 작성자를 노출하지 않는다.
- 삭제되거나 `삭제된 댓글입니다`로 남은 댓글의 이미지도 즉시 숨기고 새 열람과 다운로드를 허용하지 않는다.
- 운영자가 타인의 댓글을 삭제하면 해당 댓글 작성자에게 알림을 보낸다.

### 9.5 댓글 목록

- 최상위 댓글은 오래된 것부터 최신 순으로 표시한다.
- 처음에는 가장 오래된 댓글부터 한 페이지를 불러오고, 더 최신 댓글은 목록 하단의 `댓글 더 보기`로 이어 불러온다.
- 게시물 카드와 상세에 전체 댓글 수를 표시하며 삭제된 댓글은 세지 않는다.
- 게시물 카드의 댓글 표시를 선택하면 데스크톱에서는 게시물 상세로, 모바일에서는 댓글 하단 시트로 이동한다.
- 댓글 하단 시트는 머리글을 아래로 끌어 닫는다. 댓글 목록이 맨 위까지 올라와 있으면 목록에서 이어 당겨도 닫힌다.

## 10. 반응

### 10.1 게시물 반응

- 게시물을 열람할 수 있는 사용자는 게시물에 한 가지 반응을 남길 수 있다.
- 그룹 게시물에는 해당 게시물에 접근할 수 있는 그룹 멤버가 반응을 남길 수 있다.
- 전체 공개 개인 게시물에는 승인 사용자가 반응을 남길 수 있다.
- 비공개 개인 게시물에는 작성자 본인만 반응을 남길 수 있다.
- 반응 버튼을 짧게 누르면 기본 반응을 추가하거나 해제한다.
- 길게 누르거나 데스크톱에서 마우스를 올리면 반응 종류를 선택할 수 있다.
- 기존 반응을 다른 종류로 변경하거나 제거할 수 있다.
- 반응 종류는 좋아요, 하트, 웃겨요, 놀라워요, 슬퍼요, 화나요 여섯 가지이며 기본 반응은 좋아요다.
- 게시물에는 총 반응 수와 많이 사용된 반응을 표시하며, 많이 사용된 반응은 최대 세 종류까지 보여준다.
- 목록 보기의 행에서는 반응 수만 표시하고 반응을 남기지 않는다. 행 전체가 게시물로 가는 링크이기 때문이다.

### 10.2 댓글 반응

- 사용자는 댓글에 한 가지 반응을 남길 수 있다.
- 반응 종류를 변경하거나 반응을 제거할 수 있다.
- 익명 작성 제한 중에도 게시물과 댓글 반응은 사용할 수 있다.
- 삭제된 댓글에는 반응을 남길 수 없으며 남아 있던 반응도 표시하지 않는다.
- 댓글에는 가장 많이 사용된 반응 한 종류와 총 반응 수를 댓글 줄의 오른쪽 끝에 표시한다. 반응을 남기는 자리와 떨어뜨려, 내가 고른 반응과 남들의 반응을 구분할 수 있게 한다.
- 댓글의 반응 요약을 선택하면 게시물과 같은 참여자 목록을 연다.

### 10.3 반응 참여자 목록

- 게시물과 댓글의 반응을 전체 또는 반응 종류별로 확인한다.
- 실명 반응자는 이름, 프로필 사진, 반응 및 반응 시각을 표시한다.
- 실명 반응자는 최근 반응순으로 표시한다.

### 10.4 반응 신원

- 그룹 게시물과 댓글의 반응은 활동 신원 정책과 관계없이 실명으로 남는다.
- 반응에는 운영진 명의를 두지 않는다.

## 11. 익명 활동 관리

### 11.1 익명 활동 제한

- 그룹 소유자와 관리자는 익명 게시물 또는 댓글을 기준으로 작성자의 익명 활동을 7일 동안 제한할 수 있다.
- 운영자는 제재 과정에서 익명 작성자의 실제 신원을 확인할 수 없다.
- 운영자에게 익명 제재 대상자 명단을 제공하지 않는다.
- 동일한 활성 제재를 다시 적용해도 제한 기간을 연장하거나 알림을 반복하지 않는다.

### 11.2 제한 효과

- 선택 익명 그룹에서는 제한 기간 동안 실명으로만 게시물과 댓글을 작성한다.
- 제한 중에도 반응은 남길 수 있다.

### 11.3 제한 해제

- 소유자와 관리자는 제재를 적용한 익명 콘텐츠를 통해 제한을 해제할 수 있다.
- 제한 해제 시 별도의 알림을 보내지 않는다.
