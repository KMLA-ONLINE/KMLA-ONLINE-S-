# 메시지

## 13. 메시지

> **상태**: 구현. 기간을 정한 대화 알림 끄기(§13.17)와 그룹의 멘션 중심 알림은 아직 제공하지 않는다.

### 13.1 대화 유형

#### 1:1 대화

- 승인된 두 사용자 사이에 생성한다.
- 같은 두 사용자 사이에는 하나의 1:1 대화만 존재한다.
- 사용자는 자신과 1:1 대화를 만들 수 없다.
- 다른 사람 프로필의 `메시지 보내기`는 그 사람과의 1:1 대화가 있으면 그 대화방으로, 없으면 새로 만들어
  그 대화방으로 이동한다.
- 메시지 본문과 첨부 파일 이름은 암호화해 저장한다(§13.20).

#### 그룹 대화

- 여러 승인 사용자가 참여하는 이름 있는 대화다.
- 대화 생성자는 자동으로 멤버가 된다.
- 현재 멤버는 다른 승인 사용자를 초대할 수 있다.
- 그룹 메시지는 대화 멤버에게만 공개한다.
- 메시지 본문과 첨부 파일 이름은 암호화해 저장한다(§13.20).
- 새로 참여한 멤버는 참여한 이후에 전송된 메시지만 볼 수 있다.

### 13.2 대화 목록

- 최신 메시지가 있는 대화를 위에 표시한다.
- 메시지가 없는 대화는 아래에 표시한다.
- 각 대화에 이름, 아바타, 마지막 메시지, 마지막 메시지 시각, 읽지 않은 수 및 알림 꺼짐 상태를 표시한다.
  알림 꺼짐 상태는 대화 이름 옆 아이콘으로 표시한다.
- 마지막 메시지가 내 메시지면 `나:`를, 그룹 대화에서 다른 멤버의 메시지면 발신자 이름을 앞에 붙인다.
- 대화 이름을 검색할 수 있다.
- 넓은 화면에서 대화방을 고르지 않았을 때는 대화를 고르거나 새 대화를 시작하라는 안내와 새 대화 버튼을 표시한다.
- 대화를 열면 해당 대화의 읽음 위치를 갱신한다.

### 13.3 대화방 표시

- 대화방을 열면 대화 스크롤을 맨 아래로 이동한다. 메시지 내역은 스크롤 영역의 위쪽부터 표시한다.
- 사용자가 맨 아래에서 200px보다 위로 스크롤하면 대화 영역 아래 중앙에 테두리와 그림자가 있는 맨 아래로 이동하는 버튼을 표시한다.
- 지난 대화를 보던 중에 상대 메시지가 새로 오면 맨 아래 이동 버튼 자리에 보낸 사람의 프로필 사진, 이름과
  메시지 한 줄을 작게 표시하고, 누르면 맨 아래로 이동한다. 맨 아래에 도착하면 숨긴다.
- 맨 아래를 보고 있는 동안에는 반응이 붙거나 사진이 늦게 그려지거나 입력창 높이가 바뀌어도 맨 아래를 유지한다.
- 날짜별 구분선은 별도 배경색이나 테두리 없이 대화 배경 위에 날짜 텍스트로 표시한다. 한국 날짜로 오늘과 어제는
  `오늘`, `어제`로 표시한다.
- 시스템 메시지는 날짜 구분선과 구분되도록 옅은 배경의 둥근 띠 위에 표시한다.
- 인접한 메시지의 작성자와 표시 전송 시각이 모두 같을 때만 묶어 표시한다. 날짜 구분선과 시스템
  메시지와 `고정됨` 텍스트가 표시되는 메시지는 묶음을 나누며, 반응이 있는 메시지는 현재 묶음의
  마지막 메시지로 처리한다.
- 그룹 대화에는 작성자 이름과 프로필 사진을 표시한다. 상대 메시지 옆 프로필 사진을 누르면 그 사람의 프로필로
  이동한다.
- 대화방 헤더의 대화 이름을 누르면 대화 정보를 연다. 넓은 데스크톱에서 접어 둔 대화 정보는 다시 펼친다.
- 대화방에서 대화 목록으로 돌아간 뒤 뒤로가기로 같은 대화방에 다시 들어오지 않는다. 대화 목록에서 들어온
  대화방은 뒤로 버튼이 목록으로 되돌아가고, 다른 화면에서 들어온 대화방은 목록으로 바뀌어 그 아래가 들어오기
  전 화면이 된다. 대화방에서 다른 대화방을 열면 history를 쌓지 않고 바꾼다.
- 삭제된 메시지는 직접 보낸 같은 문구와 구분되도록 배경 없이 연한 점선 테두리, 흐린 글씨와 금지 아이콘으로
  표시한다.
- 내 메시지와 상대 메시지를 시각적으로 구분한다.
- 메시지 전송 시각은 기본으로 표시하지 않는다. 포인터 환경에서는 메시지 버블에 마우스를 올리거나 누르면
  시간 카드로 표시하고 누른 뒤에도 유지하며, 모바일에서는 메시지를 탭하면 버블 안쪽 하단에 켜고 다시
  탭하면 끄고, 길게 누르는 동안에도 같은 자리에 표시한다. 사진, 링크, 답장 인용 및 반응 표시를 탭하면
  시각을 켜지 않는다. 고정 메시지 목록에서는 묶이지 않은 메시지와 묶음의 맨 아래 메시지 안쪽 하단에
  항상 표시한다. 롱프레스 시각으로 버블이 커져도 메시지 행의 목록상 높이는 유지해 다른 메시지를 밀어내지 않는다.
- 메시지를 읽지 않은 참여자 수는 `안 읽음` 문구 없이 숫자로만 버블 바깥쪽 하단에 primary 색으로 표시한다.
  보낸 사람과 보고 있는 나는 세지 않는다. 그룹 대화에서는 상대 메시지에도 표시한다.
- 메시지 버블 옆에는 반응, 답장 및 기타 작업 버튼을 둔다. 포인터 환경에서는 호버 또는 키보드
  포커스 시 표시하고, 모바일에서는 숨긴다. 모바일에서 메시지를 길게 누르면 빠른 반응 선택 줄과
  답장, 복사 및 고정 관련 작업 메뉴를 함께 표시한다. 스크롤이나 답장 스와이프를 위해 손가락을
  움직이면 길게 누르기를 취소한다. 버튼들은 별도 테두리, 배경 및 그림자로 묶지 않고 버블의 세로
  중앙에 맞춘다.
- 모바일에서 길게 누른 메시지는 원래 목록 공간을 유지한 채 메시지 목록 영역의 세로 중앙으로
  이동한다. 빠른 반응 선택 줄과 작업 메뉴는 메시지가 중앙에 도착한 뒤 각각 위와 아래에 한 번만
  표시하고, 나머지 화면은 라이트 모드에서 반투명한 흰색, 다크 모드에서 반투명한 검은색으로 덮는다.
  메시지는 열고 닫을 때 모두 이동 애니메이션을 적용하며, 움직임 줄이기 설정에서는 애니메이션을
  생략한다. 모바일에서는 메시지 행의 텍스트를 길게 눌러 선택하지 않는다.
- 메시지 높이가 반응 선택 줄과 작업 메뉴를 함께 표시할 수 있는 대화 영역 높이를 넘으면, 메시지는
  계속 세로 중앙으로 이동하되 반응 선택 줄과 작업 메뉴는 각각 대화 영역의 위·아래 안전 여백 안에
  배치한다.
- 기타 작업 목록은 슬라이드나 별도의 등장·사라짐 애니메이션 없이 즉시 표시하고 숨긴다.
- 메시지 버블 영역의 최대 너비는 모든 화면에서 대화 영역의 78%다.
- 공백 없는 단어가 메시지 버블 너비를 넘으면 버블 안에서 강제로 줄을 바꾼다.
- HTTP(S) 링크를 선택 가능한 형태로 표시한다.
- 메시지 내용이 1개 이상 5개 이하의 이모지로만 이루어지면 버블 없이 기기의 기본 Unicode
  이모지를 크게 표시한다. `👍` 하나만 있는 메시지는 같은 크기의 좋아요 아이콘으로 표시한다.
- 삭제된 메시지는 원래 위치에 `삭제된 메시지입니다`로 표시하고, 기존 답장의 인용 영역에서도 같은 문구로 표시한다.
- 고정된 메시지와 메시지 반응을 표시한다.
- 답장 인용, 고정 메시지 목록 또는 검색 결과에서 아직 불러오지 않은 메시지로 이동하는 동안과 위로 스크롤해
  지난 메시지를 불러오는 동안에는 대화 영역 위쪽 중앙에 불러오는 중임을 표시한다.
- 답장 인용, 고정 메시지 목록 또는 검색 결과에서 원래 메시지로 이동해 강조할 때는 버블의 위치나
  주변 요소를 밀지 않는 작은 둥근 테두리를 사용한다.
- 강조 테두리의 모서리는 일반 메시지에서는 버블의 연결 상태를 따르고, 버블 없이 표시하는 이모지
  전용 메시지와 `👍` 메시지에서는 내용 전체를 감싸는 pill 형태로 표시한다.

### 13.4 메시지 작성

- 메시지는 Markdown이나 글자 서식이 없는 Unicode 평문으로 작성한다.
- 입력창은 텍스트, 줄바꿈 및 이모지가 전송 후와 같은 순서로 보이게 한다.
- 데스크톱과 모바일 입력창에서 기기의 기본 Unicode 이모지를 표시한다.
- URL은 입력 중에는 일반 텍스트로 표시하고 전송 후에만 링크로 표시한다.
- 이모지만 있는 메시지의 확대는 입력 중에는 적용하지 않는다.
- 붙여넣은 글꼴, HTML 및 글자 서식은 제거하고 평문만 입력한다.
- `Enter`로 전송하고 `Shift+Enter`로 줄을 바꾼다. 폰·태블릿의 화면 키보드에서는 `Enter`가 줄을 바꾸고 전송은 보내기 버튼으로 한다.
- 한글 IME 등 텍스트 조합 중의 `Enter`는 전송으로 처리하지 않는다.
- 전송 버튼으로 보내도 입력창 포커스를 유지해 모바일 키보드가 접히지 않는다.
- 모바일 키보드가 떠 있는 동안 대화방은 보이는 영역 안에 맞춰져 머리가 화면 위로 밀려나지 않는다.
- 메시지를 전송할 때 마지막 글자 뒤에 입력된 연속 줄바꿈은 제거하고 본문 중간의 줄바꿈은 유지한다.
- 메시지를 전송하면 대화방 스크롤을 맨 아래로 이동해 새 메시지를 표시한다. 여러 줄의 긴 메시지도 맨 아래까지
  이동한다.
- 메시지나 `좋아요`를 보낸 뒤 0.5초 안의 전송은 받지 않는다. 같은 메시지의 반응도 바꾼 뒤 0.5초 안에는 다시
  바꾸지 않는다. 입력은 지우지 않아 이어서 보낼 수 있다.
- 빈 입력 상태에서는 `좋아요`를 한 번에 전송할 수 있다. 글이나 첨부를 보낸 뒤 1초 동안은 입력이 비어도 전송
  버튼을 `좋아요`로 바꾸지 않는다.
- 작성창에는 이모지 선택기를 두지 않는다. 기기의 이모지 입력을 쓴다.
- 작성 중에는 사진·파일 첨부 아이콘을 화살표로 접어 입력창이 왼쪽으로 확장된다. 화살표를 누르거나 입력을 비우거나 메시지를 전송하면 첨부 아이콘을 다시 표시한다.
- 메시지 본문은 사용자에게 하나의 문자로 보이는 grapheme cluster 기준 최대 5,000자다.
- 보내지 않은 입력과 쌓아 둔 첨부는 다른 대화방이나 화면에 다녀와도 그 대화방에 남는다. 앱을 새로 열면 버린다.

### 13.5 메시지 첨부

- 사진과 일반 파일을 첨부한다. 작성창 옆 버튼은 파일, 사진 순서다.
- 메시지는 동영상과 GIF를 지원하지 않는다. 어느 경로로 고르든 그 파일만 빼고 알린다. 예전에 올린 동영상은
  일반 파일로 내려받는다.
- 여러 파일을 선택할 수 있다. 한 번에 사진은 최대 30장, 일반 파일은 최대 10개까지 보낸다. 넘친 것은 빼고 알린다.
- 크기 상한을 넘거나 내용이 빈 파일은 보내기 전에 빼고 알린다.
- 버튼으로 고른 파일은 바로 보낸다.
- 데스크톱에서 대화 영역이나 작성창에 끌어 놓은 파일과 입력창에 `Ctrl+V`로 붙여 넣은 사진은 바로 보내지 않고
  작성창 위에 쌓아 둔다. 하나씩 뺄 수 있고, 전송하면 입력한 글을 먼저 보내고 쌓아 둔 첨부를 이어 보낸다.
  메시지를 고치는 중에는 쌓지 않는다.
- 사진 여러 장은 하나의 사진 묶음 메시지로 전송한다. 일부 사진만 기기에서 처리하지 못하면 그 사진만 빼고 알린 뒤
  나머지를 보낸다. 업로드가 잠깐 끊긴 첨부는 그 첨부만 자동으로 다시 올린다.
- 일반 파일 여러 개는 파일별 메시지로 전송한다.
- 두 개 이상을 하나의 메시지에 첨부할 때는 각 파일이 사진이어야 한다.
- 보낸 첨부를 하나씩 지우지는 않는다. 잘못 보냈으면 메시지를 삭제한다.
- 답장 작성 중에는 파일을 첨부하지 않는다.
- 정규화된 이미지는 파일당 최대 8MiB다.
- 일반 파일과 오디오는 파일당 최대 30MiB다.
- 동영상과 GIF를 제외한 이미지가 아닌 파일은 형식과 관계없이 첨부할 수 있다.

### 13.6 첨부 콘텐츠 표시

- 사진 한 장은 원래 비율로 표시하되 9:16보다 세로로 긴 부분은 잘라 표시하고, 이미지 뷰어에서 전체를 본다.
- 사진은 격자로 최대 6칸까지 표시한다. 더 있으면 마지막 칸에 남은 수(`+N`)를 표시하고, 이미지 뷰어에서 모두
  넘겨 본다.
- 일반 파일은 파일명과 크기를 표시한다.
- 사용자는 첨부 파일을 다운로드할 수 있다. 휴대폰·태블릿의 다운로드는 [콘텐츠와 미디어](content-and-media.md)의 앱 내 다운로드를 따른다.
- MP3, M4A, OGG, WAV 및 WebM 오디오는 대화 안에서 재생한다.
- 정규화된 WebP 이미지와 지원하는 오디오 이외의 파일은 미리보기 없이 다운로드로만 제공한다. 단 휴대폰·태블릿에서
  탭한 PDF(iOS·iPadOS는 엑셀 `xlsx`·`xls`도)는 게시물 첨부와 같이 새 탭에서 바로 연다. 공유된 파일 목록도 같다.
- 오디오는 내려받은 뒤 실제 파일 형식을 확인한 경우에만 대화 안에서 재생한다. 불러오지 못했으면 재생을 다시
  눌러 새로 시도한다.

### 13.7 답장

- 특정 메시지에 답장할 수 있다.
- 모바일에서는 메시지를 가로로 밀어 답장을 시작할 수 있다.
- 작성창에 답장 대상의 작성자와 원문 일부를 표시하고 입력창으로 포커스를 옮긴다.
- 본문 없이 첨부만 있는 원문은 작성창과 답장 인용 영역에서 첨부 종류(`사진`, `파일`)로 표시한다.
- 답장을 취소할 수 있다. 입력창에서 `Esc`를 눌러도 취소한다.
- 답장 인용 영역을 선택하면 원본 메시지로 이동해 메시지 버블을 감싸 강조한다.
- 메시지에 답장한 뒤 원본 메시지가 삭제되어도 답장은 유지하며, 인용 영역에는 원문 대신 `삭제된 메시지입니다`를 표시한다.
- 삭제된 메시지에는 새 답장을 작성할 수 없다.

### 13.8 메시지 반응

- 사용자는 메시지에 한 가지 반응을 남긴다.
- 기존 반응을 다른 반응으로 변경하거나 제거한다.
- 반응 종류와 빠른 반응 선택 UI는 게시물 및 댓글 반응과 동일하게 사용한다.
- 메시지 아래 버블 바깥쪽에 반응 종류와 총수를 표시한다. 반응 그래픽은 빠른 반응 선택 UI와
  동일한 Twemoji를 사용하며, 반응 표시에 배경색과 구분되는 테두리를 두고 그림자는 두지 않는다.
  반응 표시는 버블 아래에 일부 겹치고 대화 중앙 방향으로 배치한다.
- 대화 멤버는 반응 참여자를 확인할 수 있다. 반응 시각은 표시하지 않는다.
- 반응 참여자 목록은 뒤로가기로 닫는다.

### 13.9 메시지 복사

- 텍스트 메시지를 클립보드에 복사할 수 있다. 복사하면 `복사되었습니다.`를 잠깐 표시한다.

### 13.10 메시지 편집

- 발신자는 전송 후 15분 이내에 자신의 메시지 내용을 편집할 수 있다.
- 편집한 메시지에는 수정 사실을 표시한다.
- 편집하는 사이 15분이 지나면 저장하지 않고 그 이유를 알린 뒤 편집을 끝낸다.

### 13.11 메시지 삭제

- 발신자는 자신의 메시지를 삭제할 수 있다.
- 메시지의 `삭제`를 누르면 그 메시지를 선택한 삭제 모드가 된다. 자신의 메시지를 더 선택한 뒤 아래 `삭제`
  버튼을 누르면 선택한 메시지를 한 번에 삭제한다. 별도의 `여러 개 선택` 메뉴는 두지 않는다.
- 타인의 메시지와 이미 삭제된 메시지는 선택할 수 없다. 삭제 모드에서 선택할 수 없는 메시지는 흐리게 표시하고
  반응, 답장 및 작업 메뉴를 받지 않는다. `Esc`로 삭제 모드를 끝낸다.
- 삭제하면 원래 메시지 위치에 모든 참여자에게 `삭제된 메시지입니다`로 표시한다.
- 삭제된 메시지의 본문, 첨부 및 반응은 제거한다.
- 삭제 전에 작성된 답장은 유지하며, 해당 답장의 인용 영역에는 원문 대신 `삭제된 메시지입니다`를 표시한다.

### 13.12 메시지 고정

- 대화 멤버는 메시지를 고정하거나 고정을 해제할 수 있다.
- 하나의 대화에 여러 메시지를 고정할 수 있다.
- 고정한 상대 메시지는 발신자 이름 옆에 `발신자명 · 고정됨`으로 표시하고, 고정한 내 메시지는 버블 위에
  `고정됨`을 표시한다.
- 대화 상단에는 고정된 메시지 중 대화 순서상 가장 최근 메시지의 발신자명과 내용을 두 줄로
  표시하며 별도 `고정된 메시지` 문구는 표시하지 않는다. 고정 메시지가 둘 이상이면 오른쪽에 개수를 표시한다. 본문 없이 첨부만 있는 메시지는 첨부 종류로 표시한다. 대화방 이름 아래와 메시지 입력창 위에는
  구분선을 표시하지 않고, 이 고정 메시지의 위와 아래에는 구분선을 표시한다.
- 고정 메시지 목록은 고정된 메시지만 원래 대화 순서로 배치하고, 날짜가 바뀌는 지점에는 대화방과
  동일한 날짜 텍스트를 표시한다. 메시지 사이에 별도 구분선은 표시하지 않는다.
- 목록의 각 메시지는 대화방과 동일한 프로필 사진, 발신자명, 버블 너비 및 버블 내부 전송 시각을
  표시한다. 메시지 반응, 읽지 않은 참여자 수 및 `고정됨` 문구는 목록에서 표시하지 않는다.
- 목록의 메시지 버블 옆에는 원래 메시지로 이동하는 버튼과 고정을 취소하는 버튼을 둔다. 포인터
  환경에서는 호버 또는 키보드 포커스 시 표시하고, 모바일에서는 메시지를 길게 눌렀을 때 작업
  메뉴로 표시한다.
- 목록의 메시지를 누르면 원래 메시지로 이동한다.
- 고정 메시지 목록에서 원래 메시지로 이동하면 해당 메시지 버블을 감싸 강조한다.

### 13.13 대화 내 검색

- 그룹 대화와 1:1 대화에서 메시지를 검색할 수 있다.
- 검색은 대소문자와 공백 차이를 무시한 부분 일치를 지원한다.
- 삭제된 메시지는 검색 결과에서 제외한다.
- 검색 결과에 작성자, 시각 및 본문 일부를 표시한다.
- 검색 결과의 본문 일부에는 찾은 말을 표시한다. 찾은 말이 본문 뒤쪽에 있으면 앞을 줄여 보이게 한다.
- 결과를 선택하면 원래 메시지로 이동해 메시지 버블을 감싸 강조한다. 검색을 다시 열면 입력과 결과가 남아 있어
  다음 결과를 이어 고를 수 있다. 대화방을 떠나면 버린다.
- 대화 검색 결과는 로그인 세션이 끝나면 유지하지 않는다.
- 대화 검색은 뒤로가기로 닫는다.

### 13.14 대화 정보

- 대화방 헤더와 대화 정보 상단에는 대화 이름만 표시하며 참여자 수나 현재 활동 상태는 표시하지 않는다.
- 그룹 멤버 목록에도 현재 활동 상태를 표시하지 않는다.

1:1 대화 정보에서는 다음 기능을 제공한다. 상단 빠른 동작은 프로필, 알림, 검색 순서다.

- 상대 프로필 열기
- 대화 알림 설정
- 메시지 검색
- 고정 메시지
- 공유된 미디어

그룹 대화 정보에서는 다음 기능을 제공한다. 상단 빠른 동작은 초대, 알림, 검색 순서다.

- 멤버 목록. 멤버를 누르면 그 사람의 프로필로 이동한다.
- 멤버 초대
- 그룹 대화 이름 변경
- 대화 알림 설정
- 메시지 검색
- 고정 메시지
- 공유된 미디어
- 그룹 나가기
- 대화방 삭제(소유주와 앱 관리자)

대화 정보에는 별도 메시지 암호화 안내나 개인정보 및 안전 항목을 두지 않는다.

넓은 데스크톱에서는 대화 정보를 대화방 오른쪽에 기본으로 표시하고 정보 버튼으로 접거나 다시
펼칠 수 있다. 접힘 상태는 대화방 이동과 관계없이 유지하며, 접었을 때 대화방은 우측 패널 영역까지
확장한다. 모바일과 중간 폭 화면에서는 대화 정보를 별도 화면으로 열어 대화방과 상세 내용을 순차적으로
표시한다. 별도 화면으로 연 대화 정보, 고정 메시지 목록과 그 위에 연 화면은 뒤로가기로 하나씩 닫는다.

### 13.15 그룹 대화 이름

- 모든 현재 멤버가 그룹 대화 이름을 변경할 수 있다.
- 이름은 공백을 제외한 1자 이상 50자 이하다.
- 변경한 이름은 모든 멤버에게 표시한다.

### 13.16 그룹 대화 멤버

- 모든 현재 멤버가 승인 사용자를 대화에 추가할 수 있다.
- 새 대화와 멤버 초대의 사람 찾기는 입력 중에는 찾지 않고 `Enter`를 누를 때 찾는다.
- 하나의 그룹 대화에는 최대 100명이 참여할 수 있다.
- 사용자는 그룹 대화에서 스스로 나갈 수 있다. 다른 멤버를 내보내는 기능은 두지 않는다.
- 그룹에는 소유주가 한 명 있다. 처음에는 대화를 만든 사람이고, 소유주가 나가면 가장 먼저 들어온 남은 멤버가
  소유주가 된다.
- 소유주와 앱 관리자는 확인을 거쳐 대화방을 삭제할 수 있다. 삭제하면 모든 멤버의 대화 목록에서 대화방이
  사라지고 메시지, 반응, 고정과 사진·파일도 함께 지워지며 되돌릴 수 없다. 그 대화방을 보고 있던 멤버는
  `대화방이 삭제되었습니다` 안내와 함께 대화 목록으로 이동한다.
- 나간 사용자는 참여 기간에 전송된 메시지만 계속 볼 수 있고, 이후 메시지는 볼 수 없다.
- 스스로 나간 그룹 대화는 대화 목록과 메신저 탭의 읽지 않은 수에서 빠지고, 나가면 대화 목록으로 이동한다.
- 이전에 다른 멤버를 내보낸 기록은 대화 안의 시스템 메시지로 남아 있다.

### 13.17 대화 알림

- 사용자는 대화별로 알림 받기 또는 알림 끄기를 선택한다.
- 알림은 일정 시간 또는 직접 다시 켤 때까지 끌 수 있다.
- 그룹 대화에서는 모든 메시지 또는 멘션 중심 알림 수준을 설정할 수 있다.
- 알림을 꺼도 읽지 않은 메시지 수는 유지한다.
- 메시지 읽지 않음 표시는 일반 알림함과 별도로 관리한다.
- Web Push 전체 설정을 켜면 새 메시지 Push는 기본으로 켜며 사용자는 대화별로 끌 수 있다.
- 사용자가 그 대화방을 열어 새 메시지를 이미 읽었으면 해당 메시지의 Push를 보내지 않는다. 앱의 다른 화면이나
  다른 앱을 보고 있거나 기기가 잠겨 있으면 Push를 보낸다.
- 새 메시지 Push는 기본으로 발신자와 메시지 내용을 표시한다. 1:1 대화는 발신자 이름을 제목으로, 그룹
  대화는 대화 이름을 제목으로 하고 본문 앞에 발신자 이름을 붙인다.
- 사용자는 `알림에 메시지 내용 가리기`를 켤 수 있다. 켜면 Push에 발신자와 새 메시지가 있다는 일반 안내만
  표시한다. 이 설정은 계정의 모든 기기에 적용한다.
- 웹 앱은 화면 잠금 여부를 알 수 없으므로, 잠금 화면에서만 내용을 가리려면 기기의 알림 미리보기 설정을
  사용하도록 설정 화면에서 안내한다.
- 첨부만 있는 메시지의 Push 본문은 첨부 종류(`사진`, `파일`)로 표시하고 파일 이름은 넣지 않는다.
- 같은 대화의 새 메시지 Push는 기기에서 하나의 대화별 카드로 교체해 표시한다.
- 답장은 별도 활동 알림을 추가하지 않고 원본 메시지 작성자에게 보내는 새 메시지 알림 하나로 처리한다.
- 메시지 반응은 대화 안에만 표시하고 Web Push를 보내지 않는다. 반응 변경이나 제거도 새 알림을 만들지 않는다.
- 그룹 대화에 추가되어도 별도 알림은 보내지 않고, 대화 안의 시스템 메시지로만 표시한다. 대화방 삭제도
  Web Push를 보내지 않는다.
- 멤버 가입·탈퇴, 대화 이름 변경, 메시지 고정·해제, 편집 및 삭제는 대화 안의 상태 변화로 표시하며 현재 멤버에게 별도 Web Push를 보내지 않는다.
- 그룹 대화의 멘션 중심 알림을 구현하기 전 멘션 표현, 본문과 분리된 수신자 정보 및 중복 방지 방식을 별도로 정의한다.

### 13.18 공유된 미디어

대화에서 공유된 첨부를 다음 탭으로 확인한다.

- 이미지: 이미지 수, 썸네일 격자, 추가 불러오기. 사진을 선택하면 그 사진부터 이미지 뷰어로 열고, 불러온 사진끼리
  넘겨 본다.
- 파일: 파일 수, 유형, 이름, 크기, 추가 불러오기
- 그룹 대화의 신규 멤버에게는 참여 이후에 공유된 첨부만 표시한다.
- 휴대폰 화면에서는 전체 화면으로 표시하고 뒤로가기로 닫는다.

### 13.19 이미지 뷰어

- 이미지 표시, 이동, 모바일 확대 및 UI 동작은 콘텐츠 및 미디어 공통 규칙 19.5를 따른다.
- 파일명은 화면에 표시하지 않으며 내려받는 파일 이름으로만 쓴다.

### 13.20 메시지 보안 범위

- 메시지 본문과 첨부 파일 이름은 데이터베이스에 암호문으로만 저장한다. 테이블 내용, 백업, 운영 로그를
  직접 조회해도 평문이 보이지 않는다.
- 암호화와 복호화는 서버가 하나의 서비스 키로 수행하며, 사용자는 평문으로 메시지를 주고받는다.
  데이터베이스 관리자 권한이나 서비스 키 접근 권한을 가진 운영자는 메시지를 복호화할 수 있다. 이 설계는
  종단간 암호화가 아니다.
- 메시지를 볼 수 있는 범위는 대화 멤버십과 참여 기간으로 서버가 강제한다. 새 멤버는 참여 이전 메시지를,
  나간 사용자는 이후 메시지를 볼 수 없다.
- 첨부 파일 내용은 별도로 암호화하지 않고 대화 멤버만 접근할 수 있는 비공개 Storage 버킷에 저장한다.
- 대화 참여자, 전송 시각, 메시지 수, 파일 형식과 크기, 읽음, 반응 및 고정 상태는 암호화 대상에 포함하지 않는다.
- 게시물은 메시지 암호화 대상이 아니다.
- 보안 범위를 사용자에게 안내할 때는 위 보장 범위를 사실대로 설명한다.

### 13.21 게시물 공유 메시지

- 본문이 큼온 게시물 상세 링크 하나뿐인 메시지는 버블 대신 게시물 카드로 표시한다. 게시물 보내기(기능 명세
  §8.13)로 보낸 메시지와 링크만 붙여넣어 보낸 메시지가 모두 해당한다. 다른 글과 함께 쓴 링크와 첨부에 붙인 링크는
  일반 링크로 표시한다.
- 답장이면 원문 인용을 카드 위에 표시한다. 편집된 메시지는 카드 아래에 `수정됨`을 표시한다.
- 카드에는 게시물 사진 한 장, 작성자 표시 이름, 그룹 이름(개인 게시물이면 표시하지 않음), 제목 또는 본문
  앞부분을 표시한다. 익명 게시물은 게시물에 표시되는 이름만 쓰고, 운영진 명의 게시물은 게시물과 같이 실제 이름에
  운영진 표시를 붙인다. 프로필 사진·커버 변경 활동은 바꾼 사진과 변경 문구를 표시한다. 카드를 누르면 게시물 상세를 연다.
- 보는 사람이 읽을 수 없는 게시물(멤버가 아닌 그룹의 게시물, 작성자만 보는 게시물, 삭제된 게시물)은
  `볼 수 없는 게시물입니다` 카드로 표시한다.
- 게시물을 불러오지 못하면 볼 수 없는 게시물과 구분되는 문구와 다시 시도 버튼을 표시한다.
- 내가 게시물을 고치거나 지우거나 그룹을 나가면 내 화면의 카드에 바로 반영한다. 다른 사람의 변경과 그룹에서
  내보내진 경우는 2분 안에 반영된다.
- 대화 목록의 마지막 메시지와 답장 인용에서는 링크 대신 `게시물`로 부른다. Push 알림은 본문을 그대로 쓴다.

구현 방식은 [메시지 기술 설계](../MESSAGING_TECHNICAL_DESIGN.md)를 따른다.
