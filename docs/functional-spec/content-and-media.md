# 콘텐츠 및 미디어 공통 규칙

## 18. 콘텐츠 및 미디어 공통 규칙

### 18.1 이미지 처리

- 프로필, 그룹, 게시물, 댓글 및 메시지 이미지 업로드를 지원한다.
- JPEG, PNG 및 WebP만 입력으로 받으며 GIF, SVG, HEIC는 지원하지 않는다.
- 입력 이미지는 파일당 최대 30MiB 및 50메가픽셀이다.
- 위치, 기기 및 촬영 정보와 같은 메타데이터를 제거한다.
- 모든 이미지를 WebP 품질 0.85로 다시 인코딩하며 원본은 보존하지 않고, 원본보다 큰 해상도로 확대하지 않는다.
- 용도별 상한은 다음과 같다.
  - 프로필 사진과 그룹 아이콘: 긴 변 512px, 최대 1MiB
  - 프로필 및 그룹 커버: 긴 변 2400px, 최대 4MiB
  - 게시물, 댓글 및 메시지 사진: 긴 변 3072px, 최대 8MiB
- 변환 결과가 크기 상한을 넘으면 품질을 추가로 낮추지 않고 업로드를 거부한다.

### 18.2 파일 접근

- 프로필 및 그룹 이미지는 해당 프로필이나 그룹을 볼 수 있는 사용자에게 제공한다.
- 그룹 게시물 첨부는 해당 게시물에 접근할 수 있는 그룹 멤버에게 제공한다.
- 전체 공개 개인 게시물 첨부는 승인 사용자에게, 비공개 개인 게시물 첨부는 작성자 본인에게만 제공한다.
- 댓글 이미지는 부모 게시물과 같은 열람 권한을 적용하되, 댓글이 삭제되거나 삭제 자리 표시로 남으면 즉시 숨기고 새 접근을 거부한다.
- 메시지 첨부는 해당 대화의 멤버에게 제공하며, 내용과 파일 이름은 클라이언트에서 암호화한 뒤 저장한다.
- 접근 권한을 잃기 전에 발급받은 파일 URL은 발급 후 최대 1시간까지 유효할 수 있다.

### 18.3 콘텐츠 보존

- 삭제된 게시물과 그 댓글은 일반 사용자에게 더 이상 표시하지 않는다.
- 삭제된 댓글에 활성 답글이 남아 있으면 대화 연결을 위해 `삭제된 댓글입니다` 표시를 유지한다.
- 삭제되거나 자리 표시만 남은 댓글의 이미지는 표시하지 않고 연결된 파일을 정리한다.
- 삭제된 메시지는 원래 위치에 `삭제된 메시지입니다`로 남기고, 기존 답장의 인용 영역에도 같은 문구를 표시한다.
- 탈퇴 사용자의 기존 콘텐츠는 작성자를 `탈퇴한 사용자`로 익명화해 유지한다.

### 18.4 글꼴 및 이모지

- 사용자가 작성하는 텍스트에는 원래 Unicode 이모지를 저장하고, 게시물·댓글·메시지의 입력과 출력에는 기기의 기본 이모지를 표시한다.
- 반응 그래픽에는 기기와 무관하게 같은 그림을 쓰기 위해 Twemoji SVG를 사용하고, 반응 종류에 해당하는 파일만 서비스에 포함한다.
- 사용자는 콘텐츠의 글꼴을 지정할 수 없으며 서비스가 정한 공통 글꼴과 대체 글꼴을 사용한다.

### 18.5 이미지 뷰어

- 게시물과 댓글의 인라인 이미지 미리보기를 선택하면 같은 이미지 뷰어를 열며 다운로드 기능도 동일하게 제공한다.
- 게시물 첨부, 댓글 첨부 및 프로필 변경 활동 이미지는 각 이미지의 UUID에 `.webp`를 붙인 이름으로 다운로드한다. 이미지가 아닌 첨부 파일은 원본 이름을 유지한다.
- 이미지는 원본 비율을 유지하고 잘리지 않도록 화면 안의 최대 크기로 표시한다.
- 현재 이미지 순서를 표시하고 이전 또는 다음 이미지로 이동하며 이미지를 다운로드할 수 있다.
- 데스크톱에서는 이동 버튼, 방향키 및 하단 썸네일 목록을 제공한다.
- 모바일에서는 하단 썸네일 목록을 표시하지 않고 좌우 밀기로 이미지를 이동한다.
- 모바일에서 이미지를 한 번 누르면 주변 UI를 숨기고 다시 누르면 복원한다. UI는 이미지 위에 겹쳐 표시하므로 표시 여부와 관계없이 이미지 영역의 크기와 세로 중앙 위치는 유지한다.
- 모바일에서 두 손가락으로 1배부터 4배까지 확대·축소하고, 확대된 이미지는 한 손가락으로 이동한다.
- 모바일에서 이미지를 두 번 누르면 누른 위치를 중심으로 2배 확대하며, 확대된 상태에서 두 번 누르면 1배로 복원한다.
- 확대 배율이 1배일 때만 좌우 밀기로 이미지를 전환한다. 이미지를 전환하거나 뷰어를 다시 열면 확대 상태를 초기화한다.
