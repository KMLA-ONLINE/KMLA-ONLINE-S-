# 메시지

## 13. 메시지

### 13.1 대화 유형

#### 1:1 대화

- 승인된 두 사용자 사이에 생성한다.
- 같은 두 사용자 사이에는 하나의 1:1 대화만 존재한다.
- 사용자는 자신과 1:1 대화를 만들 수 없다.
- 메시지 본문, 첨부 파일 및 첨부 파일 이름을 종단간 암호화한다.

#### 그룹 대화

- 여러 승인 사용자가 참여하는 이름 있는 대화다.
- 대화 생성자는 자동으로 멤버가 된다.
- 현재 멤버는 다른 승인 사용자를 초대할 수 있다.
- 그룹 메시지는 대화 멤버에게만 공개한다.
- 메시지 본문, 첨부 파일 및 첨부 파일 이름을 종단간 암호화한다.
- 새로 참여한 멤버는 참여한 이후에 전송된 메시지만 복호화할 수 있다.

### 13.2 대화 목록

- 최신 메시지가 있는 대화를 위에 표시한다.
- 메시지가 없는 대화는 아래에 표시한다.
- 각 대화에 이름, 아바타, 마지막 메시지, 마지막 메시지 시각, 읽지 않은 수 및 알림 꺼짐 상태를 표시한다.
- 대화 이름을 검색할 수 있다.
- 대화를 열면 해당 대화의 읽음 위치를 갱신한다.

### 13.3 대화방 표시

- 날짜별 구분선을 표시한다.
- 같은 작성자의 연속 메시지를 묶어 표시한다.
- 그룹 대화에는 작성자 이름과 프로필 사진을 표시한다.
- 내 메시지와 상대 메시지를 시각적으로 구분한다.
- 메시지 전송 시각과 읽은 참여자를 표시한다.
- 링크를 선택 가능한 형태로 표시한다.
- 이모지만 있는 메시지는 크게 표시한다.
- 삭제된 메시지를 인용한 활성 답장이 있으면 대화 연결을 위해 삭제 표시를 남긴다.
- 고정된 메시지와 메시지 반응을 표시한다.

### 13.4 메시지 작성

- 텍스트 메시지를 작성한다.
- `Enter`로 전송하고 `Shift+Enter`로 줄을 바꾼다.
- 빈 입력 상태에서는 `좋아요`를 한 번에 전송할 수 있다.
- 이모지 선택기를 사용할 수 있다.
- 메시지 본문은 최대 5,000자다.

### 13.5 메시지 첨부

- 사진과 일반 파일을 첨부한다.
- 여러 파일을 선택할 수 있다.
- 데스크톱에서 파일을 대화 영역으로 끌어놓을 수 있다.
- 사진과 동영상 여러 개는 하나의 미디어 묶음 메시지로 전송한다.
- 일반 파일 여러 개는 파일별 메시지로 전송한다.
- 메시지 하나에 최대 10개 파일을 첨부한다.
- 두 개 이상을 하나의 메시지에 첨부할 때는 각 파일이 이미지 또는 동영상이어야 하며 두 종류를 함께 첨부할 수 있다.
- 답장 작성 중에는 파일을 첨부하지 않는다.
- 발신자는 전송한 메시지의 첨부를 개별적으로 제거할 수 있다.
- 본문 없이 첨부만 있던 메시지에서 마지막 첨부를 제거하면 메시지도 삭제한다.
- 정규화된 이미지는 파일당 최대 8MiB다.
- 일반 파일과 오디오는 암호화 전 파일당 최대 30MiB다.
- 동영상은 암호화 전 파일당 최대 30MiB다.
- 이미지가 아닌 파일은 형식과 관계없이 첨부할 수 있다.

### 13.6 첨부 콘텐츠 표시

- 사진은 격자로 표시한다.
- 일반 파일은 파일명과 크기를 표시한다.
- 사용자는 첨부 파일을 다운로드할 수 있다.
- MP3, M4A, OGG, WAV 및 WebM 오디오는 대화 안에서 재생한다.
- MP4, WebM 및 MOV 동영상은 대화 안에서 재생한다.
- 정규화된 WebP 이미지와 지원하는 오디오·동영상 이외의 파일은 미리보기 없이 다운로드로만 제공한다.
- 오디오와 동영상은 복호화 후 실제 파일 형식을 확인한 경우에만 대화 안에서 재생한다.

### 13.7 답장

- 특정 메시지에 답장할 수 있다.
- 모바일에서는 메시지를 가로로 밀어 답장을 시작할 수 있다.
- 작성창에 답장 대상의 작성자와 원문 일부를 표시한다.
- 답장을 취소할 수 있다.
- 답장 인용 영역을 선택하면 원본 메시지로 이동해 강조한다.
- 삭제된 메시지에는 새 답장을 작성할 수 없다.

### 13.8 메시지 반응

- 사용자는 메시지에 한 가지 반응을 남긴다.
- 기존 반응을 다른 반응으로 변경하거나 제거한다.
- 메시지 아래에 반응 종류와 총수를 표시한다.
- 대화 멤버는 반응 참여자와 반응 시각을 확인할 수 있다.

### 13.9 메시지 복사 및 전달

- 텍스트 메시지를 클립보드에 복사할 수 있다.
- 메시지를 다른 대화로 전달할 수 있다.
- 전달할 메시지와 첨부는 현재 기기에서 복호화한 뒤 대상 대화의 암호화 키로 다시 암호화한다.

### 13.10 메시지 편집

- 발신자는 전송 후 15분 이내에 자신의 메시지 내용을 편집할 수 있다.
- 편집한 메시지에는 수정 사실을 표시한다.
- 편집한 내용은 같은 암호화 nonce를 재사용하지 않고 새 nonce로 암호화한다.

### 13.11 메시지 삭제

- 발신자는 자신의 메시지를 삭제할 수 있다.
- 삭제 모드에서 자신의 메시지를 여러 개 선택해 한 번에 삭제할 수 있다.
- 타인의 메시지와 이미 삭제된 메시지는 선택할 수 없다.
- 삭제하면 모든 참여자에게 삭제된 메시지로 표시한다.
- 삭제된 메시지의 본문, 첨부, 반응 및 암호화 정보는 제거한다.
- 삭제된 메시지를 인용한 답장이 있으면 대화 연결을 위해 삭제 표시를 유지한다.

### 13.12 메시지 고정

- 대화 멤버는 메시지를 고정하거나 고정을 해제할 수 있다.
- 하나의 대화에 여러 메시지를 고정할 수 있다.
- 대화 상단에 최근 고정 메시지를 표시한다.
- 고정 메시지 목록에서 작성자, 작성 시각 및 내용을 확인한다.
- 목록에서 원래 메시지로 이동하거나 고정을 해제할 수 있다.

### 13.13 대화 내 검색

- 그룹 대화와 1:1 대화에서 메시지를 검색할 수 있다.
- 검색은 대소문자와 공백 차이를 무시한 부분 일치를 지원한다.
- 삭제된 메시지는 검색 결과에서 제외한다.
- 검색 결과에 작성자, 시각 및 본문 일부를 표시한다.
- 결과를 선택하면 원래 메시지로 이동해 강조한다.
- 대화 검색 결과는 로그인 세션이 끝나면 유지하지 않는다.

### 13.14 대화 정보

1:1 대화 정보에서는 다음 기능을 제공한다.

- 상대 프로필 열기
- 대화 알림 설정
- 메시지 검색
- 고정 메시지
- 공유된 미디어
- 종단간 암호화 안내

그룹 대화 정보에서는 다음 기능을 제공한다.

- 멤버 목록
- 멤버 초대
- 그룹 대화 이름 변경
- 대화 알림 설정
- 메시지 검색
- 고정 메시지
- 공유된 미디어

### 13.15 그룹 대화 이름

- 모든 현재 멤버가 그룹 대화 이름을 변경할 수 있다.
- 이름은 공백을 제외한 1자 이상 50자 이하다.
- 변경한 이름은 모든 멤버에게 표시한다.

### 13.16 그룹 대화 멤버

- 모든 현재 멤버가 승인 사용자를 대화에 추가할 수 있다.
- 하나의 그룹 대화에는 최대 100명이 참여할 수 있다.
- 사용자는 자신을 그룹 대화에서 내보낼 수 있다.
- 대화 생성자는 다른 멤버를 내보낼 수 있다.
- 앱 관리자는 그룹 대화에서 다른 멤버를 내보낼 수 있다.
- 내보낸 사용자의 과거 메시지는 대화에 남는다.
- 대화에 참여하지 않은 앱 관리자가 멤버를 내보내면 남은 멤버가 새 암호화 키를 배포할 때까지 새 메시지 전송을 일시 중지한다.

### 13.17 대화 알림

- 사용자는 대화별로 알림 받기 또는 알림 끄기를 선택한다.
- 알림은 일정 시간 또는 직접 다시 켤 때까지 끌 수 있다.
- 그룹 대화에서는 모든 메시지 또는 멘션 중심 알림 수준을 설정할 수 있다.
- 알림을 꺼도 읽지 않은 메시지 수는 유지한다.
- 메시지 읽지 않음 표시는 일반 알림함과 별도로 관리한다.

### 13.18 공유된 미디어

대화에서 공유된 첨부를 다음 탭으로 확인한다.

- 이미지: 이미지 수, 썸네일 격자, 추가 불러오기
- 파일: 파일 수, 유형, 이름, 크기, 추가 불러오기
- 그룹 대화의 신규 멤버에게는 참여 이후에 공유되어 복호화할 수 있는 첨부만 표시한다.

### 13.19 이미지 뷰어

- 이미지를 전체 화면으로 연다.
- 파일명과 현재 이미지 순서를 표시한다.
- 이전 또는 다음 이미지로 이동한다.
- 모바일에서 좌우 밀기, 데스크톱에서 버튼과 방향키 이동을 지원한다.
- 하단 썸네일 목록에서 이미지를 선택한다.
- 이미지를 다운로드할 수 있다.

### 13.20 메시지 보안 범위

- 데이터베이스, Storage 및 운영 로그에 저장된 값을 조회하는 서버 운영자는 1:1 및 그룹 메시지 본문, 첨부 내용 및 첨부 파일 이름을 읽을 수 없다.
- 대화 참여자, 전송 시각, 메시지 수, 파일 형식과 크기, 읽음, 반응 및 고정 상태는 암호화 대상에 포함하지 않는다.
- 게시물은 종단간 암호화 대상이 아니다.
- 메시지 암호화에는 별도의 복구 코드나 서버 복구 키를 제공하지 않는다.
- 그룹 대화에 새로 참여한 멤버에게는 참여 이전 메시지를 복호화할 수 있는 키를 제공하지 않는다.
- 그룹 멤버가 추가되거나 나가거나 내보내지면 이후 메시지에 사용할 암호화 키를 교체한다.
- 그룹에서 나가거나 내보내진 사용자는 참여 중 받은 과거 메시지를 계속 복호화할 수 있지만 이후 메시지는 복호화할 수 없다.
- 종단간 암호화는 데이터베이스, Storage 및 운영 로그를 조회하는 관리자의 저장 데이터 열람을 막는 것을 보장 범위로 한다.
- 관리자가 배포된 클라이언트 코드를 변경하거나 클라이언트 기기와 로그인 세션을 탈취하는 공격은 보장 범위에 포함하지 않는다.
