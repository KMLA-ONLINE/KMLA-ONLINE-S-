# 메시지

## 13. 메시지

### 13.1 대화 유형

#### 1:1 대화

- 승인된 두 사용자 사이에 생성한다.
- 같은 두 사용자 사이에는 하나의 1:1 대화만 존재한다.
- 사용자는 자신과 1:1 대화를 만들 수 없다.
- 메시지 본문, 첨부 파일 및 첨부 파일 이름은 클라이언트에서 암호화한 뒤 저장한다.

#### 그룹 대화

- 여러 승인 사용자가 참여하는 이름 있는 대화다.
- 대화 생성자는 자동으로 멤버가 된다.
- 현재 멤버는 다른 승인 사용자를 초대할 수 있다.
- 그룹 메시지는 대화 멤버에게만 공개한다.
- 메시지 본문, 첨부 파일 및 첨부 파일 이름은 클라이언트에서 암호화한 뒤 저장한다.
- 새로 참여한 멤버는 참여한 이후에 전송된 메시지만 복호화할 수 있다.

### 13.2 대화 목록

- 최신 메시지가 있는 대화를 위에 표시한다.
- 메시지가 없는 대화는 아래에 표시한다.
- 각 대화에 이름, 아바타, 마지막 메시지, 마지막 메시지 시각, 읽지 않은 수 및 알림 꺼짐 상태를 표시한다.
  알림 꺼짐 상태는 대화 이름 옆 아이콘으로 표시한다.
- 대화 이름을 검색할 수 있다.
- 대화를 열면 해당 대화의 읽음 위치를 갱신한다.

### 13.3 대화방 표시

- 날짜별 구분선은 별도 배경색이나 테두리 없이 대화 배경 위에 날짜 텍스트로 표시한다.
- 같은 작성자의 연속 메시지를 묶어 표시한다.
- 그룹 대화에는 작성자 이름과 프로필 사진을 표시한다.
- 내 메시지와 상대 메시지를 시각적으로 구분한다.
- 메시지 전송 시각은 각 메시지 버블 안쪽 하단에 표시한다.
- 내 메시지를 읽지 않은 참여자 수는 `안 읽음` 문구 없이 숫자로만 버블 바깥쪽 하단에 primary 색으로 표시한다.
- 메시지 버블 옆에는 반응, 답장 및 기타 작업 버튼을 둔다. 포인터 환경에서는 호버 또는 키보드
  포커스 시 표시하고, 호버할 수 없는 터치 환경에서는 항상 사용할 수 있게 표시한다. 버튼들은
  별도 테두리, 배경 및 그림자로 묶지 않고 버블의 세로 중앙에 맞춘다.
- 기타 작업 목록은 슬라이드나 별도의 등장·사라짐 애니메이션 없이 즉시 표시하고 숨긴다.
- HTTP(S) 링크를 선택 가능한 형태로 표시한다.
- 이모지만 1개가 있는 메시지는 전송 후 크게 표시한다.
- 삭제된 메시지는 원래 위치에 `삭제된 메시지입니다`로 표시하고, 기존 답장의 인용 영역에서도 같은 문구로 표시한다.
- 고정된 메시지와 메시지 반응을 표시한다.

### 13.4 메시지 작성

- 메시지는 Markdown이나 글자 서식이 없는 Unicode 평문으로 작성한다.
- 입력창은 텍스트, 줄바꿈 및 이모지가 전송 후와 같은 순서로 보이게 한다.
- 데스크톱과 모바일 입력창에서 기기의 기본 Unicode 이모지를 표시한다.
- URL은 입력 중에는 일반 텍스트로 표시하고 전송 후에만 링크로 표시한다.
- 이모지만 있는 메시지의 확대는 입력 중에는 적용하지 않는다.
- 붙여넣은 글꼴, HTML 및 글자 서식은 제거하고 평문만 입력한다.
- `Enter`로 전송하고 `Shift+Enter`로 줄을 바꾼다.
- 한글 IME 등 텍스트 조합 중의 `Enter`는 전송으로 처리하지 않는다.
- 메시지를 전송할 때 마지막 글자 뒤에 입력된 연속 줄바꿈은 제거하고 본문 중간의 줄바꿈은 유지한다.
- 빈 입력 상태에서는 `좋아요`를 한 번에 전송할 수 있다.
- 이모지 선택기는 데스크톱에서 사용할 수 있으며 모바일에서는 숨긴다.
- 메시지 본문은 사용자에게 하나의 문자로 보이는 grapheme cluster 기준 최대 5,000자다.

### 13.5 메시지 첨부

- 사진과 일반 파일을 첨부한다.
- 여러 파일을 선택할 수 있다.
- 데스크톱에서 파일을 대화 영역으로 끌어놓을 수 있다.
- 사진과 동영상 여러 개는 하나의 미디어 묶음 메시지로 전송한다.
- 일반 파일 여러 개는 파일별 메시지로 전송한다.
- 메시지 하나에 최대 10개 파일을 첨부한다.
- 두 개 이상을 하나의 메시지에 첨부할 때는 각 파일이 이미지 또는 동영상이어야 하며 두 종류를 함께 첨부할 수 있다.
- 답장 작성 중에는 파일을 첨부하지 않는다.
- 발신자는 전송한 메시지의 첨부를 개별적으로 제거할 수 있다.
- 본문 없이 첨부만 있던 메시지에서 마지막 첨부를 제거하면 메시지도 삭제한다.
- 정규화된 이미지는 파일당 최대 8MiB다.
- 일반 파일과 오디오는 암호화 전 파일당 최대 30MiB다.
- 동영상은 암호화 전 파일당 최대 30MiB다.
- 이미지가 아닌 파일은 형식과 관계없이 첨부할 수 있다.

### 13.6 첨부 콘텐츠 표시

- 사진은 격자로 표시한다.
- 일반 파일은 파일명과 크기를 표시한다.
- 사용자는 첨부 파일을 다운로드할 수 있다.
- MP3, M4A, OGG, WAV 및 WebM 오디오는 대화 안에서 재생한다.
- MP4, WebM 및 MOV 동영상은 대화 안에서 재생한다.
- 정규화된 WebP 이미지와 지원하는 오디오·동영상 이외의 파일은 미리보기 없이 다운로드로만 제공한다.
- 오디오와 동영상은 복호화 후 실제 파일 형식을 확인한 경우에만 대화 안에서 재생한다.

### 13.7 답장

- 특정 메시지에 답장할 수 있다.
- 모바일에서는 메시지를 가로로 밀어 답장을 시작할 수 있다.
- 작성창에 답장 대상의 작성자와 원문 일부를 표시한다.
- 답장을 취소할 수 있다.
- 답장 인용 영역을 선택하면 원본 메시지로 이동해 강조한다.
- 메시지에 답장한 뒤 원본 메시지가 삭제되어도 답장은 유지하며, 인용 영역에는 원문 대신 `삭제된 메시지입니다`를 표시한다.
- 삭제된 메시지에는 새 답장을 작성할 수 없다.

### 13.8 메시지 반응

- 사용자는 메시지에 한 가지 반응을 남긴다.
- 기존 반응을 다른 반응으로 변경하거나 제거한다.
- 반응 종류와 빠른 반응 선택 UI는 게시물 및 댓글 반응과 동일하게 사용한다.
- 메시지 아래에 반응 종류와 총수를 표시한다.
- 대화 멤버는 반응 참여자와 반응 시각을 확인할 수 있다.

### 13.9 메시지 복사

- 텍스트 메시지를 클립보드에 복사할 수 있다.

### 13.10 메시지 편집

- 발신자는 전송 후 15분 이내에 자신의 메시지 내용을 편집할 수 있다.
- 편집한 메시지에는 수정 사실을 표시한다.
- 편집한 내용은 같은 암호화 nonce를 재사용하지 않고 새 nonce로 암호화한다.

### 13.11 메시지 삭제

- 발신자는 자신의 메시지를 삭제할 수 있다.
- 삭제 모드에서 자신의 메시지를 여러 개 선택해 한 번에 삭제할 수 있다.
- 타인의 메시지와 이미 삭제된 메시지는 선택할 수 없다.
- 삭제하면 원래 메시지 위치에 모든 참여자에게 `삭제된 메시지입니다`로 표시한다.
- 삭제된 메시지의 본문, 첨부, 반응 및 암호화 정보는 제거한다.
- 삭제 전에 작성된 답장은 유지하며, 해당 답장의 인용 영역에는 원문 대신 `삭제된 메시지입니다`를 표시한다.

### 13.12 메시지 고정

- 대화 멤버는 메시지를 고정하거나 고정을 해제할 수 있다.
- 하나의 대화에 여러 메시지를 고정할 수 있다.
- 고정한 상대 메시지는 발신자 이름 옆에 `발신자명 · 고정됨`으로 표시하고, 고정한 내 메시지는 버블 위에
  `고정됨`을 표시한다.
- 대화 상단에는 고정된 메시지 중 대화 순서상 가장 최근 메시지의 발신자명과 내용을 두 줄로
  표시하며 별도 `고정된 메시지` 문구는 표시하지 않는다.
- 고정 메시지 목록은 고정된 메시지만 원래 대화 순서로 배치하고, 날짜가 바뀌는 지점에는 대화방과
  동일한 날짜 텍스트를 표시한다. 메시지 사이에 별도 구분선은 표시하지 않는다.
- 목록의 각 메시지는 대화방과 동일한 프로필 사진, 발신자명, 버블 너비 및 버블 내부 전송 시각을
  표시한다. 메시지 반응, 읽지 않은 참여자 수 및 `고정됨` 문구는 목록에서 표시하지 않는다.
- 목록의 메시지 버블 옆에는 원래 메시지로 이동하는 버튼과 고정을 취소하는 버튼을 둔다. 노출 방식은
  대화방의 반응 및 답장 버튼과 동일하게 포인터 환경에서는 호버 또는 키보드 포커스 시 표시하고,
  호버할 수 없는 터치 환경에서는 항상 표시한다.

### 13.13 대화 내 검색

- 그룹 대화와 1:1 대화에서 메시지를 검색할 수 있다.
- 검색은 대소문자와 공백 차이를 무시한 부분 일치를 지원한다.
- 삭제된 메시지는 검색 결과에서 제외한다.
- 검색 결과에 작성자, 시각 및 본문 일부를 표시한다.
- 결과를 선택하면 원래 메시지로 이동해 강조한다.
- 대화 검색 결과는 로그인 세션이 끝나면 유지하지 않는다.

### 13.14 대화 정보

- 대화방 헤더와 대화 정보 상단에는 대화 이름만 표시하며 참여자 수나 현재 활동 상태는 표시하지 않는다.
- 그룹 멤버 목록에도 현재 활동 상태를 표시하지 않는다.

1:1 대화 정보에서는 다음 기능을 제공한다.

- 상대 프로필 열기
- 대화 알림 설정
- 메시지 검색
- 고정 메시지
- 공유된 미디어
- 메시지 암호화 안내

현재 목 UI 단계에서는 상대 프로필 빠른 동작을 알림 및 검색과 함께 표시하되 비활성화한다.

그룹 대화 정보에서는 다음 기능을 제공한다.

- 멤버 목록
- 멤버 초대
- 그룹 대화 이름 변경
- 대화 알림 설정
- 메시지 검색
- 고정 메시지
- 공유된 미디어

넓은 데스크톱에서는 대화 정보를 대화방 오른쪽에 기본으로 표시하고 정보 버튼으로 접거나 다시
펼칠 수 있다. 모바일과 중간 폭 화면에서는 대화 정보를 별도 화면으로 열어 대화방과 상세 내용을
순차적으로 표시한다.

### 13.15 그룹 대화 이름

- 모든 현재 멤버가 그룹 대화 이름을 변경할 수 있다.
- 이름은 공백을 제외한 1자 이상 50자 이하다.
- 변경한 이름은 모든 멤버에게 표시한다.

### 13.16 그룹 대화 멤버

- 모든 현재 멤버가 승인 사용자를 대화에 추가할 수 있다.
- 하나의 그룹 대화에는 최대 100명이 참여할 수 있다.
- 사용자는 자신을 그룹 대화에서 내보낼 수 있다.
- 대화 생성자는 다른 멤버를 내보낼 수 있다.
- 앱 관리자는 그룹 대화에서 다른 멤버를 내보낼 수 있다.
- 내보낸 사용자의 과거 메시지는 대화에 남는다.
- 그룹 멤버를 추가하거나 멤버가 나가거나 내보내지는 상태 전이에서 Edge Function이 이후 메시지용 암호화 키를 즉시 교체한다.

### 13.17 대화 알림

- 사용자는 대화별로 알림 받기 또는 알림 끄기를 선택한다.
- 알림은 일정 시간 또는 직접 다시 켤 때까지 끌 수 있다.
- 그룹 대화에서는 모든 메시지 또는 멘션 중심 알림 수준을 설정할 수 있다.
- 알림을 꺼도 읽지 않은 메시지 수는 유지한다.
- 메시지 읽지 않음 표시는 일반 알림함과 별도로 관리한다.
- Web Push 전체 설정을 켜면 새 메시지 Push는 기본으로 켜며 사용자는 대화별로 끌 수 있다.
- 답장은 별도 활동 알림을 추가하지 않고 원본 메시지 작성자에게 보내는 새 메시지 알림 하나로 처리한다.
- 메시지 반응은 대화 안에만 표시하고 Web Push를 보내지 않는다. 반응 변경이나 제거도 새 알림을 만들지 않는다.
- 사용자가 그룹 대화에 추가되면 보통 중요도의 대화 알림을 보내고, 그룹 대화에서 내보내지면 높음 중요도의 알림을 보낸다.
- 멤버 가입·탈퇴·내보내기, 대화 이름 변경, 메시지 고정·해제, 편집 및 삭제는 대화 안의 상태 변화로 표시하며 현재 멤버에게 별도 Web Push를 보내지 않는다.
- 메시지 본문과 첨부 파일 이름은 서버에서 읽을 수 없으므로 Web Push에는 발신자와 새 메시지가 있다는 일반 안내만 표시하고 평문 미리보기를 넣지 않는다.
- 그룹 대화의 멘션 중심 알림을 구현하기 전 멘션 표현, 암호화된 본문과 분리된 수신자 정보 및 중복 방지 방식을 별도로 정의한다.

### 13.18 공유된 미디어

대화에서 공유된 첨부를 다음 탭으로 확인한다.

- 이미지: 이미지 수, 썸네일 격자, 추가 불러오기
- 파일: 파일 수, 유형, 이름, 크기, 추가 불러오기
- 그룹 대화의 신규 멤버에게는 참여 이후에 공유되어 복호화할 수 있는 첨부만 표시한다.

### 13.19 이미지 뷰어

- 이미지 표시, 이동, 모바일 확대 및 UI 동작은 콘텐츠 및 미디어 공통 규칙 19.5를 따른다.
- 파일명은 화면에 표시하지 않으며 내려받는 파일 이름으로만 쓴다.

### 13.20 메시지 보안 범위

- 데이터베이스, Storage 및 운영 로그에 저장된 값을 조회하는 서버 운영자는 1:1 및 그룹 메시지 본문, 첨부 내용 및 첨부 파일 이름을 읽을 수 없다.
- 대화 참여자, 전송 시각, 메시지 수, 파일 형식과 크기, 읽음, 반응 및 고정 상태는 암호화 대상에 포함하지 않는다.
- 게시물은 메시지 클라이언트 암호화 대상이 아니다.
- 대화 암호화 키는 데이터베이스가 아닌 Edge Function의 비밀 키로 보호하며 사용자 비밀번호와 결합하지 않는다.
- 그룹 대화에 새로 참여한 멤버에게는 참여 이전 메시지를 복호화할 수 있는 키를 제공하지 않는다.
- 그룹 멤버가 추가되거나 나가거나 내보내지면 이후 메시지에 사용할 암호화 키를 교체한다.
- 그룹에서 나가거나 내보내진 사용자는 참여 중 받은 과거 메시지를 계속 복호화할 수 있지만 이후 메시지는 복호화할 수 없다.
- 메시지 암호화는 데이터베이스, Storage 및 운영 로그에 저장된 값을 직접 조회하는 관리자의 평문 열람을 막는 것을 보장 범위로 한다.
- Edge Function의 비밀 키나 배포 권한을 가진 관리자, 데이터베이스의 멤버십과 키 정보를 능동적으로 변조하는 관리자, 클라이언트 기기 또는 로그인 세션을 탈취한 공격자는 보장 범위에 포함하지 않는다.
