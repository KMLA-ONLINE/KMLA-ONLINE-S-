# 프로필

## 12. 프로필

### 12.1 프로필 열람

- 사용자는 자신의 프로필과 다른 승인 사용자의 프로필을 열람한다.
- 프로필의 정식 URL은 고유 공개 ID를 쓰는 `/profile/:pubId`이며, `/profile`은 현재 로그인한 사용자의 프로필로 이동하는 편의 경로다.
- 공개 ID는 영문 소문자, 숫자, 하이픈으로 구성된 5자 이상 15자 이하의 문자열이며 대소문자를 구분하지 않고 고유하다.
- 혼동을 일으킬 수 있는 `admin`, `administrator`, `teacher`, `staff`, `moderator`, `support`, `system`, `root`, `sibal`은 공개 ID로 사용할 수 없다.
- 게시물 작성자, 댓글 작성자, 그룹 멤버에서 프로필로 이동할 수 있다.

프로필에는 다음 정보를 표시한다.

- 프로필 사진과 커버 사진
- 이름과 앱 관리자 배지
- 기수, 계열, 교사 표시. 복학생의 기수는 `n.5기`로 표시한다
- 학번, 반, 부서, 기숙사 방, 성별, 생일, 전화번호, 연락용 이메일 중 값이 있는 항목
- 소개
- 프로필 타임라인

표시 규칙은 다음과 같다.

- 정보 항목은 학적 정보, 연락처, 기타 정보로 묶어 표시한다. 값이 하나도 없는 묶음은 표시하지 않는다.
- 좁은 화면에서는 첫 묶음만 표시하고 더 보기와 접기로 나머지 묶음을 펼치거나 접는다. 넓은 화면에서는 모든 묶음을 표시한다.
- 소개는 처음에 두 줄까지 표시하며, 잘린 경우 더보기와 접기로 전체 내용을 펼치거나 접을 수 있다.
- 전화번호와 연락용 이메일은 처음에 일부를 가려 표시한다. 전화번호는 마지막 네 자리 숫자를, 연락용 이메일은 로컬 파트 앞 두 글자와 도메인을 남긴다. 이는 프로필이 명부처럼 읽히지 않게 하는 표시 규칙이며 열람 권한을 제한하지 않는다.
- 가려진 전화번호나 연락용 이메일을 선택하면 전체 값을 표시하고, 표시된 값을 다시 선택하면 전화 연결 또는 메일 작성을 시작한다.
- 프로필 타임라인에서 해당 사용자를 대상으로 작성된 개인 게시물을 최신순으로 확인하며, 프로필 당사자는 자신의 비공개 게시물도 함께 본다.

### 12.2 프로필 편집

자신의 프로필 편집 화면은 `/profile/:pubId/edit`이며 프로필 당사자만 접근할 수 있다.

모든 사용자는 다음 항목을 편집한다.

- 이름
- 소개
- 생일
- 전화번호
- 연락용 이메일
- 타인의 내 타임라인 게시물 작성 허용 여부

재학생은 성별, 계열, 부서, 반, 기숙사 방과 재입학 여부를, 졸업생은 성별과 계열을 편집한다. 교사는 학적 정보를 사용하지 않는다.

입력 제한은 다음과 같다.

- 이름은 1자 이상 50자 이하다.
- 소개는 최대 500자다.
- 전화번호는 앞자리 `+`를 허용하는 숫자, 공백, 하이픈 조합으로 8자 이상 20자 이하다.
- 연락용 이메일은 이메일 형식이어야 한다.
- 반은 1 이상 10 이하, 기숙사 방은 101 이상 1008 이하다.

사용자는 기수, 학번, 사용자 유형, 계정 상태, 앱 관리자 역할 및 공개 ID를 직접 변경할 수 없다.

### 12.3 프로필 이미지 편집

- 자신의 프로필 사진과 커버 사진을 등록, 변경 및 자를 수 있다.
- 프로필 사진은 1:1, 커버 사진은 3:1 비율로 자르며, 이미지를 이동하고 확대·축소해 사용할 영역을 정한다.
- JPEG, PNG, WebP 입력을 지원하며 저장 전 WebP로 재인코딩해 메타데이터를 제거하고 용량을 제한한다.
- 프로필 사진이나 커버 사진을 등록 또는 변경하면 자신의 타임라인에 전체 공개 활동 게시물을 만든다. 활동 게시물에는 변경 당시 이미지 하나와 `이름님이 프로필 사진을 바꾸었습니다.` 또는 `이름님이 프로필 커버를 바꾸었습니다.` 문구를 표시한다.
- 기본 이미지로 되돌릴 때는 활동 게시물을 만들지 않는다.

### 12.4 프로필 타임라인

- 승인 사용자는 자신의 타임라인과 다른 승인 사용자의 타임라인을 열람한다.
- 타임라인에는 해당 프로필을 대상으로 작성된 전체 공개 개인 게시물을 최신순으로 표시하고, 자신의 타임라인에서는 자신이 작성한 비공개 게시물도 함께 표시한다.
- 타임라인 당사자가 타인 작성을 허용하면 다른 승인 사용자가 해당 타임라인에 글을 작성할 수 있다. 허용하지 않은 타임라인에서는 글쓰기 진입점을 표시하지 않으며 설정값을 문구로 알리지 않는다.
- 타인 작성 허용을 꺼도 기존 타인 게시물은 유지하며 당사자가 개별적으로 삭제할 수 있다. 당사자는 타인이 작성한 글을 수정할 수 없다.
- 타임라인은 게시물을 카드로만 표시하며 카드·목록 보기 전환과 카테고리 필터를 두지 않는다.
- 타임라인에서 게시물을 선택하면 그룹 게시물과 같은 모양의 게시물 상세를 연다.
- 프로필 미디어 변경 활동은 수정할 수 없지만 일반 개인 게시물과 같이 댓글, 반응, 공유 및 작성자 삭제를 지원한다.
