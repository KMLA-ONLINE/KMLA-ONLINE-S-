# ADR 재도입과 기록 위치 구분

**상태**: 채택 · **날짜**: 2026-11-09

#247은 ADR을 없애고 결정 이유를 코드 주석과 소유 문서에 적도록 했다. 그 결과 여러 곳에 걸친
결정의 이유·버린 대안·변경 시점을 둘 곳이 없어졌다. 그래서 ADR을 다시 도입하되, 현재 규칙은
계속 소유 문서가 맡고 ADR은 결정의 이유와 이력만 맡는다. 코드 주석, feature `AGENTS.md`,
소유 문서, ADR의 경계는 [ADR 안내](README.md#기록-위치)를 따른다.

## 검토한 대안

- **#247처럼 ADR 없이 운영**: 현재 정책 문서에 과거 결정의 경위가 섞이거나, 대체된 결정의
  이유가 함께 지워진다.
- **#247 이전 정책을 그대로 복원**: 소유 문서 우선과 ADR 기준은 같지만, 코드 주석이 맡을
  범위가 정해져 있지 않았다.
- **ADR을 모든 결정의 기본 위치로 사용**: 현재 규칙을 알려면 ADR 여러 개를 시간순으로 읽어야
  하고, 명세·기술 설계와 정본이 둘이 된다.
