# 홈 통합 피드 랭킹 설계

## 1. 문서 목적

이 문서는 [피드 및 그룹 기능 명세](functional-spec/02-feed-and-groups.md)의 후보 선별, 랭킹, `#업`, 출처 제한 및 페이지네이션을 구현하기 위한 기술 경계를 정의한다. 게시물의 작성 신원과 접근 권한은 [게시물 및 상호작용 기능 명세](functional-spec/03-posts-and-interactions.md)를 따른다.

피드는 추천 시스템이 아니라 최신순을 중심으로 최근 상호작용과 출처 다양성을 약하게 반영하는 규칙 기반 목록이다. 한 페이지는 20개다.

## 2. 후보와 현재 접근 권한

피드 후보는 다음 세 집합의 합집합이다.

- 작성자와 타임라인 당사자가 같은 전체 공개 개인 게시물. 프로필 사진·커버 등록 또는 변경 활동을 포함한다.
- 사용자가 현재 가입한 그룹의 게시물.
- 작성자와 타임라인 당사자가 다른 공개 개인 게시물 중 관련 기수 필터를 통과한 생탐.

생탐은 타임라인 당사자의 관련 기수와 보는 사용자의 관련 기수가 겹칠 때만 포함한다. 일반 재학생은 자신의 현재 기수, 복학생은 `cohort`와 `cohort + 1`을 관련 기수로 사용한다. 졸업생은 자신의 관련 기수 중 현재 승인된 재학생이 실제로 속한 기수가 하나 이상 있을 때만 생탐 후보를 받는다. 교사와 관련 기수가 없는 사용자는 생탐 후보를 받지 않는다.

피드 세션은 접근 권한을 부여하는 자료가 아니다. 각 페이지를 반환하기 직전에 현재 승인 상태, 그룹 멤버십, 공개 범위, 게시·삭제 상태와 RLS를 다시 검사한다. 세션 생성 뒤 접근을 잃은 게시물은 즉시 제외하고 빈자리는 세션의 다음 후보로 채운다. 새로 얻은 멤버십이나 공개 전환으로 접근 가능해진 게시물은 새 피드 세션에서 반영한다. 즉, 과거 스냅샷은 현재 접근 제한을 우회할 수 없다.

## 3. 랭킹

### 3.1 기준 시각

첫 페이지 요청을 처리하는 데이터베이스 트랜잭션의 서버 시각을 `feed_epoch`으로 사용한다. 작성 시각은 `published_at`이다. 그룹 고정 상태는 홈 피드 순위에 반영하지 않는다.

최근 6시간의 일반 게시물에는 다음 보정을 적용한다.

```text
R = feed_epoch 시점의 반응 수
C = 다른 사용자가 작성한 삭제되지 않은 최상위 댓글 수
age = feed_epoch - published_at
interaction_boost = min(4분 × R + 8분 × C, 40분 × (1 - age / 6시간))
```

`C`에서 답글, 게시물 실제 작성자의 댓글 및 본문이 정확히 `#업`인 댓글은 제외한다. 작성자 비교에는 표시용 신원이 아니라 비공개 관계에 저장된 실제 작성자를 사용한다. 6시간이 지난 게시물의 `interaction_boost`는 0이다.

생탐은 게시 후 6시간 구간에서 계산된 시각에서 60분을 뺀다. 6시간 이후에는 다른 게시물과 같은 최신순 규칙을 사용한다. 동점은 `published_at DESC, post_id DESC`처럼 변경되지 않는 키로 해소한다.

### 3.2 `#업` 랭킹 시각

유효 `#업`이 있는 그룹 게시물은 가장 최근의 유효 사건 시각을 기본 랭킹 시각으로 사용하고 상호작용 보정을 다시 적용하지 않는다. `published_at`은 바꾸지 않는다. 따라서 `#업`은 게시물을 새 게시물로 만들지 않으며 그룹 내부 정렬에도 영향을 주지 않는다.

## 4. 유효 `#업` 사건

`#업`은 댓글 행의 현재 본문을 조회할 때마다 추론하지 않고 댓글 삽입 트랜잭션에서 변경 불가능한 사건으로 기록한다. 사건에는 최소한 게시물 ID, 원인 댓글 ID 및 서버 발생 시각이 필요하다.

다음 조건을 모두 만족하는 댓글 삽입만 사건을 만든다.

- 게시물이 게시·삭제되지 않은 그룹 게시물이고 작성자가 현재 댓글을 작성할 수 있다.
- 댓글 깊이가 0이다.
- 작성 신원이 실명 또는 운영진이다.
- 앞뒤 공백을 제거한 전체 본문이 정확히 `#업`이다.
- 같은 게시물의 직전 유효 `#업` 사건부터 서버 시각으로 1시간 이상 지났다.

조건 확인과 사건 삽입은 하나의 데이터베이스 트랜잭션에서 같은 게시물 단위로 직렬화해 동시 요청이 쿨다운을 우회하지 못하게 한다. 쿨다운 중 등록된 `#업`은 일반 댓글로 남지만 사건을 만들지 않는다.

사건은 댓글 수정으로 생성할 수 없고, 댓글 수정·삭제나 작성 신원 표시 변화로 수정 또는 삭제하지 않는다. 이 불변 이벤트 기록이 과거 피드 세션의 순위와 감사 가능한 쿨다운 기준을 보존한다. 운영진 명의의 화면 표시는 실제 작성자 이름·사진과 운영진 배지를 함께 보여 주는 게시물 기능 명세를 따른다.

## 5. 정확한 피드 세션

`feed_epoch`만 담은 커서로 매 페이지의 순위를 다시 계산하지 않는다. 반응 변경·삭제, 댓글 삭제 및 새 `#업` 때문에 과거 상태를 mutable 집계에서 정확히 복원할 수 없기 때문이다.

첫 페이지 요청은 서버 측 피드 세션을 만들고 같은 트랜잭션 스냅샷에서 다음을 확정한다.

- `feed_epoch`
- 후보 게시물 ID와 해당 시점의 정렬 키
- 정렬 동점 순서
- 아직 반환하지 않은 후보와 출처 제한으로 미룬 후보
- 마지막으로 반환한 출처와 연속 개수

첫 페이지와 이후 페이지는 클라이언트가 해석하거나 조작하지 않는 세션 ID 및 페이지 토큰으로 조회한다. 세션에서 이미 확정한 순위와 상호작용 수를 다시 계산하지 않으므로 같은 세션에서는 새 게시물, 반응, 댓글, 댓글 삭제 또는 `#업`이 중복·누락·순서 변경을 만들지 않는다. 5초가 지난 뒤 새로고침하면 새 세션과 새 `feed_epoch`을 만들며, 5초 안의 중복 첫 페이지 요청은 같은 세션을 재사용한다.

세션 자료는 사용자별 비공개 서버 자료이며 다른 사용자가 읽거나 이어 받을 수 없다. 활성 세션은 사용자당 최근 8개를 유지하고 만료되거나 제한으로 제거된 세션은 같은 `feed_epoch`인 것처럼 조용히 재생성하지 않고 새 피드가 필요함을 반환한다. 표시용 댓글·반응 수는 현재 값을 사용할 수 있지만 세션에 확정된 랭킹 입력과 혼동하지 않는다.

## 6. 출처 제한과 지연 큐

출처는 개인 게시물의 실제 작성자 또는 그룹 게시물의 그룹이다. 생탐도 개인 게시물이므로 실제 작성자를 출처로 사용한다.

| 출처                      | 연속 제한 | 페이지 제한 |
| ------------------------- | --------: | ----------: |
| 같은 사용자의 개인 게시물 |       2개 |         4개 |
| 같은 그룹의 게시물        |       3개 |        10개 |

페이지를 만들 때 확정된 랭킹 순서대로 후보를 검사한다. 연속 제한이나 현재 페이지 제한을 넘는 후보는 삭제하지 않고 세션의 지연 큐에 보관한다. 페이지 제한 카운터는 페이지마다 초기화하고, 연속 제한은 페이지 경계를 넘어 마지막으로 실제 반환한 항목부터 이어 계산한다.

엄격한 제한으로 20개를 채우지 못하면 지연 큐와 남은 후보를 원래 랭킹 순서로 다시 검사해 필요한 만큼 제한을 완화한다. 이때도 접근 불가능한 게시물은 완화 대상이 아니다. 이번 페이지에 사용하지 않은 지연 후보는 다음 페이지에 그대로 남기며, 완화 때문에 더 낮은 후보가 먼저 반환되었더라도 지연 후보를 삭제하지 않는다.

이 절차는 두 제한을 모두 실제로 적용하면서도 후보가 존재하는 경우 페이지 크기를 우선하고, 특정 출처의 게시물이 페이지네이션 과정에서 영구 누락되는 것을 막는다.

## 7. 응답과 화면 경계

한 페이지는 게시물 20개와 다음 페이지용 불투명 토큰을 반환한다. 응답에는 카드와 목록 보기에 필요한 게시물, 대상, 작성 신원, 작성 시각, 댓글·반응 요약, 이미지와 첨부 정보를 함께 담아 게시물별 추가 조회를 만들지 않는다.

운영진 명의는 익명 신원이 아니다. 피드에서도 실제 작성자의 이름과 프로필 사진, 프로필 이동 및 운영진 배지를 제공한다. 익명 게시물만 실제 작성자 표시 정보를 노출하지 않는다.

카드와 목록 보기는 동일한 세션과 순서를 사용한다. 오늘의 급식 카드는 홈 화면에 유지한다. 오늘의 생일 영역은 연기하며 생일 여부를 후보나 점수에 사용하지 않는다.

피드 읽음 상태는 저장하지 않는다. `last_feed_seen_at`, 읽음 테이블, 읽음 갱신 RPC, 새 게시물 개수·점 표시 및 피드 게시물별 로컬 방문 기록을 만들지 않는다. 그룹 게시물 목록이 별도로 유지하는 기기 로컬 방문 상태는 피드 세션과 무관하며 그대로 유지한다.

## 8. 검증 기준

- 같은 세션의 여러 페이지에서 새 상호작용과 `#업`이 발생해도 게시물 중복, 누락 또는 기존 순서 변경이 없다.
- 댓글 수정은 `#업` 사건을 만들지 않고, 유효 사건의 원인 댓글을 수정·삭제해도 사건은 남는다.
- 같은 게시물에 동시에 등록한 `#업` 중 1시간 쿨다운을 통과한 사건은 최대 하나다.
- 연속 제한은 페이지 경계를 넘어서 적용되고 페이지 제한은 새 페이지에서 초기화된다.
- 제한으로 미룬 게시물은 후속 페이지 또는 부족분을 채우는 완화 단계에서 반환된다.
- 세션 중 그룹 탈퇴, 승인 취소, 비공개 전환 또는 삭제가 발생하면 다음 응답에서 해당 게시물을 반환하지 않는다.
- 프로필 미디어 활동과 관련 기수 조건을 만족하는 생탐이 후보에 포함되고, 졸업생 생탐 조건은 현재 승인된 재학생 기수와 대조한다.
- 홈 피드 응답과 클라이언트 상태에 읽음·새 글·방문 표시 자료가 없다.
